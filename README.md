# 北ハイテク HTML・CSS講座

架空のカフェサイトの更新を通して、HTML・CSSから確認・公開まで学ぶ15回（30時間）の教材です。

## 始め方

1. 自分用のコピーまたは作業ブランチを用意する。共有の`main`は編集しない。
2. [Codespaceを起動](https://codespaces.new/hgsk/edu)し、エクスプローラーに`README.md`と`hht`が見えることを確認する。個人コピーを使う場合は、そのリポジトリのCodeメニューからCodespaceを作成する。
3. 役割に合う入口から今日の教材を開く。

- [学生向け入口](./hht/student/README.md)
- [講師向け入口](./hht/instructor/README.md)
- [教材全体の案内](./hht/README.md)
- [Google Cloud 練習インスタンスの接続手順](./hht/docs/google-cloud-practice.md)
