# 北ハイテク HTML・CSS講座

架空のカフェサイトの更新を通して、HTML・CSSから確認・公開まで学ぶ15回（30時間）の教材です。

## 始め方

1. 自分用のコピーまたは**作業ブランチ**を用意する。共有の`main`は編集しない。
2. Codespacesまたは**Visual Studio Code**で**リポジトリのルート**を開く。`README.md`と`hht`が見えることを確認する。
3. Codespacesを使う場合は[Codespaceを起動](https://codespaces.new/hgsk/edu)する。個人コピーでは、そのリポジトリのCodeメニューからCodespaceを作成する。
4. 役割に合う入口から今日の教材を開く。

- [講師向け入口](./hht/instructor/README.md)
- [教材全体の案内](./hht/README.md)
