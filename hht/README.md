# HTML・CSS講座の教材案内

架空のカフェ「NORTH LIGHT COFFEE」の更新を題材に、15回・30時間で依頼の確認、HTML・CSSの修正、表示確認、公開を学びます。  
DAY 14・15ではポートフォリオを扱います。  
全15回に専用の開始データがあり、他のDAYの完成物がなくても取り組めます。

## はじめて使う人へ

[Documentsへクローンする手順](./docs/workbook/common.md#clone-edu)に沿って、GitHubの`hgsk/edu`を取得します。  
PCのVS Codeで`Documents/edu`全体を開きます。  
次回からも同じフォルダーを使います。

## 今日の授業へ

**課題の正本は[学生ワークブック](./docs/student-workbook.md)です。**  
学生向け入口や授業パックは、各回の教材への案内です。

- **課題を選ぶ：** [全15回の目次](./docs/student-workbook.md)から今回のDAYを開きます。
- **DAYフォルダーを開く：** [各DAYの開始手順](./docs/workbook/common.md#independent-day-start)を使います。
- **変更を記録する：** [共通の作業手順と作業メモ](./docs/workbook/common.md#local-git-workflow)を確認します。
- **VS Codeの操作を練習する：** [VS Codeハンズオン](./docs/vscode-hands-on.md)を使います。

全15回でローカルGitを使い、制作ファイル・作業メモ・必要な画像の変更履歴を残します。
