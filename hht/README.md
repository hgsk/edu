# HTML・CSS講座の教材案内

架空のカフェ「NORTH LIGHT COFFEE」の更新を題材に、15回・30時間で小規模サイトの制作、確認、公開を学びます。  
最後に自分のポートフォリオも制作します。

## 今日の授業へ

**課題の正本は[学生ワークブック](./docs/student-workbook.md)です。**  
学生向け入口や授業パックは、各回の教材への案内です。

- **学生:** [学生向け入口](./student/README.md)から今回の授業の教材を開く。
- **講師:** [講師向け入口](./instructor/README.md)から今日の授業パックを開く。
- **Codespaces専用の参考資料（今回の受講手順では使いません）:** [はじめてツアー](./tour/README.md)。
- **PCのVS Codeで受講する人:** [VS Codeハンズオン手順](./docs/vscode-hands-on.md)から始める。  
  講師は[VS Codeでの進行資料](./docs/vscode-instructor-guide.md)を使う。

本人用のローカルGitリポジトリをPCのVS Codeで開きます。  
作業の進め方は[正本の共通Gitの作業手順](./docs/workbook/common.md#local-git-workflow)を確認します。
