## 授業時間の見立て

各120分の配分は正本の各DAY末尾に置きました。既存コードの書き写しだけでは120分を使い切る根拠が弱く、比較・小さな変更・複数条件での検証・報告を含めた配分です。実授業の所要時間は未計測なので、120分かかることを保証する記録ではありません。

2回を13:30〜16:40に実施する場合は、13:30〜15:00と15:10〜16:40の各90分、間に10分休憩が目安です。各回の依頼10分・観察10分・試行15分・改善25分・検証20分・報告10分を軸にし、発展と全体共有を省きます。素材の所在と継続サイトの準備を授業前に済ませ、実習時間を確保します。
