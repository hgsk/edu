# 15回・30時間カリキュラム

## 授業の位置づけ

- 授業回数: 15回
- 1回の授業時間: 120分
- 総授業時間: 30時間
- 対象: 高校生・専門学校生
- 技術範囲: HTMLとCSS
- 制作方法: Visual Studio Codeとブラウザを使った個人演習
- 題材: 架空カフェ「NORTH LIGHT COFFEE」の更新・改善案件

昨年度の「開発環境→HTML→CSS→id/class→ブロック→ヘッダー／フッター→レイアウト→フォーム→メイン／サイド→高度なCSS→スマートフォン対応→CSSアニメーション」の順序を維持し、各回へ受注、対象確認、実装、検証、クライアント報告を組み込みます。

指定書籍は副教材です。授業は本カリキュラムの実務課題を中心に進め、技術事項の復習やサンプル差分の確認にChapter 1〜4を使用します。JavaScript、DOM、Ajax、jQuery、Vue.jsは別授業の範囲です。

## 標準の120分

| 時間 | 活動 |
|---:|---|
| 0〜10分 | 前回の振り返り、今回の依頼確認 |
| 10〜35分 | HTML／CSSの技術解説とデモ |
| 35〜45分 | 対象、手順、確認項目を計画 |
| 45〜95分 | 個人実装と途中確認 |
| 95〜110分 | ブラウザ、コード、アクセシビリティ、差分の検証 |
| 110〜118分 | クライアントへの確認・報告文 |
| 118〜120分 | 提出、次回予告 |

回によって技術解説と演習の配分を変えますが、合計は必ず120分です。

## 第1回 オリエンテーション・ブラウザ・エディター

**技術:** ファイルとフォルダー、拡張子、`<!doctype html>`、`html`、`head`、`body`、文字コード、ブラウザ再読込
