# 15回・30時間カリキュラム

## この授業について

- 授業回数: 15回
- 1回の授業時間: 120分
- 総授業時間: 30時間
- 対象: 高校生・専門学校生
- 技術範囲: HTMLとCSS
- 制作方法: 教材と作品を分け、VS Codeとブラウザで確認する個人演習
- 題材: 架空カフェ「NORTH LIGHT COFFEE」の更新・改善案件

HTMLとCSSを少しずつ学びながら、架空のカフェサイトを育てていきます。  
毎回、お客さまから新しい依頼が届きます。  
「どこを直す？」  
「ほかのページは大丈夫？」  
と考え、制作、確認、報告まで挑戦します。

開始時は[共通手順](./workbook/common.md)で教材を更新します。  
DAY1〜9は基礎練習、DAY10〜15は同じ作品を継続制作します。  
全DAYの提出はGitHub PRです。

教材更新と作品のローカルGit記録を区別します。  
DAY1のステージング公開・復元は維持し、後半の外部公開を必須へ拡大しません。

## 毎回の120分

各回は、お客さまから届く依頼を開くところから始めます。  
先に技術の説明を聞くのではなく、「この仕事を終えるには何を覚えればよいか」を考えてからHTML・CSSを学びます。

- 導入講義5分: 「今日は何を学ぶ？  
  この依頼のどこが気になる？」  
  と講師が問いかける
- 前半55分: 依頼を読む5分 → 作戦会議20分 → 必要な技を試す30分
- 後半55分: 制作のヒント10分 → 制作・ペア確認20分 → 仕上げ・検証・返信25分
- 振り返り講義5分: 「みんなはどうした？  
  講師ならどうする？」  
  を一緒に振り返る

毎回のゴールは画面を完成させることだけではありません。  
依頼された範囲を守り、分からないことを質問し、確認結果をお客さまへ伝えたところで、その日の仕事が完了します。  
各回の詳しい進行と記入欄は `docs/student-workbook.md` を使います。


**課題条件の正本：** [学生ワークブック](./student-workbook.md)。  
本書は講師の進行と学習観点を示し、完成の条件は正本を参照します。

## 第1回 オリエンテーション・ブラウザ・エディター

**昨年度項目:** オリエンテーション、ブラウザ・エディターの用意、HTMLに触れてみる

**この回のゴール:** 依頼メールのToとCCを確認し、自分でHTMLファイルを作ってブラウザに表示してみよう。  
練習サイトを公開し、いつでも元に戻せるバックアップを作って、自習をすぐ再開できるようにしよう。

**120分:** 導入講義5分／依頼確認5分／作戦会議15分／開発者ツール演習15分／HTML・公開技術演習25分／制作・ペア確認20分／仕上げ・検証・返信30分／振り返り講義5分

**技術:** ファイルとフォルダー、拡張子、エディター設定と補完、`<!doctype html>`、`html`、`head`、`body`、文字コード、ブラウザ再読込、開発者ツールのElements・Styles・Console・端末表示、ローカルHTTPサーバー、練習環境へのデプロイ、バージョン管理、バックアップ、復元

**やってみよう:** 最初の依頼メールを読み、「受け取りました」と返信しよう。  
開発者ツールで`h1`と適用中のCSSを見つけ、一時変更が再読み込みで戻ることを確かめよう。  
375px幅とConsoleを確認してから、最初の状態をバージョンとして保存し、練習用公開先へのデプロイと復元を一度ずつ試そう。

**できたかチェック:** [ワークブック DAY 1](./workbook/day01.md#day-1-はじめての依頼メール)の完成条件・確認項目を参照。
