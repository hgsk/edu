# 15回・30時間カリキュラム

## この授業について

- 授業回数: 15回
- 1回の授業時間: 120分
- 総授業時間: 30時間
- 対象: 高校生・専門学校生
- 技術範囲: HTMLとCSS
- 制作方法: 毎回本人用のローカルGitリポジトリをVS Codeで開き、ブラウザと組み合わせて行う個人演習
- 題材: 架空カフェ「NORTH LIGHT COFFEE」の更新・改善案件

HTMLとCSSを少しずつ学びながら、架空のカフェサイトを育てていきます。  
毎回、お客さまから新しい依頼が届きます。  
「どこを直す？」  
「ほかのページは大丈夫？」  
と考え、制作、確認、報告まで挑戦します。

授業開始時は、受講者ごとのコピーまたはブランチで本人用のローカルGitリポジトリのルートをPCのVS Codeで開きます。  
`hht`や`references/cafe-site`だけを単独で開かず、授業パック、依頼資料、制作ファイル、変更差分、バージョン履歴を一つのワークスペースで扱います。

## 毎回の120分

各回は、お客さまから届く依頼を開くところから始めます。  
先に技術の説明を聞くのではなく、「この仕事を終えるには何を覚えればよいか」を考えてからHTML・CSSを学びます。

- 導入講義5分: 「今日は何を学ぶ？  
  この依頼のどこが気になる？」  
  と講師が問いかける
- 前半55分: 依頼を読む5分 → 作戦会議20分 → 必要な技を試す30分
- 後半55分: 制作のヒント10分 → 制作・ペア確認20分 → 仕上げ・検証・返信25分
- 振り返り講義5分: 「みんなはどうした？  
  講師ならどうする？」  
  を一緒に振り返る

毎回のゴールは画面を完成させることだけではありません。  
依頼された範囲を守り、分からないことを質問し、確認結果をお客さまへ伝えたところで、その日の仕事が完了します。  
各回の詳しい進行と記入欄は `docs/student-workbook.md` を使います。


**課題条件の正本：** [学生ワークブック](./student-workbook.md)。  
本書は講師の進行と学習観点を示し、完成の条件は正本を参照します。

[夏祭りサイト 新年度版制作ハンズオン](../hands-on/summer-festival-annual-update/README.md)は、第10回終了後の追加演習、または第11〜13回の統合課題との差し替えに使えます。  
前年版サイトと2027年度の企画資料を比較し、音楽ステージ、学校協賛、日時、雨天対応、構造化データを安全に更新します。  
15回・30時間の本編へ加える場合は、総時間が増えないよう講師が差し替える回を事前に示します。

最初から上手に作れなくても大丈夫です。  
授業の中で考え、試し、少しずつできることを増やしていきましょう。  
合格までの道は2つあります。

- **授業参加ルート:** 授業に参加して、考えたことや作業したことを毎回記録する
- **作品完成ルート:** 最後の作品を完成させ、どこをどう直したか自分の言葉で説明する

成績の記録では、毎回の課題40%・中間課題20%・最後の作品40%を目安にします。  
ただし、パスワードを公開する、OKをもらう前にサイトを公開する、使ってよいか分からない画像を使う、依頼されていない場所を大きく変える、といった危険なミスがあった場合はやり直します。
