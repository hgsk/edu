# 15回・30時間カリキュラム

## この授業について

- 授業回数: 15回
- 1回の授業時間: 120分
- 総授業時間: 30時間
- 対象: 高校生・専門学校生
- 技術範囲: HTMLとCSS
- 制作方法: Visual Studio Codeとブラウザを使った個人演習
- 題材: 架空カフェ「NORTH LIGHT COFFEE」の更新・改善案件

HTMLとCSSを少しずつ学びながら、架空のカフェサイトを育てていきます。毎回、お客さまから新しい依頼が届きます。「どこを直す？」「ほかのページは大丈夫？」と考え、制作、確認、報告まで挑戦します。

## 毎回の120分

各回は、お客さまから届く依頼を開くところから始めます。先に技術の説明を聞くのではなく、「この仕事を終えるには何を覚えればよいか」を考えてからHTML・CSSを学びます。

- 前半60分: 依頼を読む10分 → 作戦会議20分 → 必要な技を試す30分
- 後半60分: 制作のヒント10分 → 制作・ペア確認20分 → 仕上げ・検証・返信30分

毎回のゴールは画面を完成させることだけではありません。依頼された範囲を守り、分からないことを質問し、確認結果をお客さまへ伝えたところで、その日の仕事が完了します。各回の詳しい進行と記入欄は `docs/student-workbook.md` を使います。

## 第1回 オリエンテーション・ブラウザ・エディター

**昨年度項目:** オリエンテーション、ブラウザ・エディターの用意、HTMLに触れてみる

**この回のゴール:** 自分でHTMLファイルを作り、ブラウザに表示してみよう。依頼メールでは「だれから、だれへ、何を、いつまでに」を見つけよう。

**120分:** 講義10分／ディスカッション20分／ハンズオン30分／講義10分／ディスカッション20分／ハンズオン30分

**技術:** ファイルとフォルダー、拡張子、`<!doctype html>`、`html`、`head`、`body`、文字コード、ブラウザ再読込

**やってみよう:** 最初の依頼メールを読み、「受け取りました」と返信しよう。カフェサイトを開き、画面の文字がどのファイルに書かれているか探そう。

**提出物:** 環境確認表、最初のHTML、依頼整理票、受領返信

**できたかチェック:** HTMLに書いた日本語がブラウザに表示された。CCに入っている人と、最後にOKを出す人の違いが分かった。

## 成績について

最初から上手に作れなくても大丈夫です。授業の中で考え、試し、少しずつできることを増やしていきましょう。合格までの道は2つあります。

- **授業参加ルート:** 授業に参加して、考えたことや作業したことを毎回記録する
- **作品完成ルート:** 最後の作品を完成させ、どこをどう直したか自分の言葉で説明する

成績の記録では、毎回の課題40%・中間課題20%・最後の作品40%を目安にします。ただし、パスワードを公開する、OKをもらう前にサイトを公開する、使ってよいか分からない画像を使う、依頼されていない場所を大きく変える、といった危険なミスがあった場合はやり直します。
