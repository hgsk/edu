# 求人5社から導く発展スキル

## 結論

5社が求めているのは、単にHTMLとCSSを書ける人ではありません。依頼を事業目的へ変換し、制作物を設計し、他者へ指示し、CMS・ECの制約内で実装し、期限と品質を管理できる人です。

発展講座では、基礎講座の「小さな更新を安全に完了する力」を、次の5領域へ広げます。

1. Webディレクションとプロジェクト管理
2. 情報設計、ワイヤーフレーム、デザインシステム
3. WordPressの設計・テーマ・移行・保守
4. ECの商品情報、購入導線、モール・プラットフォーム運用
5. SEO、撮影、品質保証、応募・継続受注

## 共通して評価される能力

### 1. 要件を定義する

- 目的、利用者、競合、成功指標を聞く
- ページ一覧、機能、コンテンツ、担当、期限、予算、対象外を確定する
- 「お任せ」「高品質」「暖かい」「参考サイトと同等」を検証可能な条件へ変える
- 変更要求を記録し、納期・費用・品質への影響を説明する

### 2. 設計を見える形にする

- 現行サイトのコンテンツ棚卸し
- サイトマップとユーザーフロー
- 低忠実度ワイヤーフレーム
- コンポーネントと状態の定義
- デスクトップ、モバイル、エラー、空状態の指示
- デザインからコーダーへ渡す注釈と受入条件

### 3. 進行と連絡を管理する

- WBS、マイルストーン、依存関係、担当、期限
- 24時間以内の一次返信を想定した連絡ルール
- 会議前のアジェンダ、会議後の決定・未決・担当・期限
- 遅延を隠さず、影響と回復案を早く共有する
- チャット、メール、課題管理で情報を重複・散逸させない

「返信が速い」は即答することではなく、受領、次の回答時刻、必要な確認を明確に返すことです。

### 4. 品質を管理する

- 要件とテスト項目を対応づける
- デザイン、実装、文章、リンク、フォーム、SEO、アクセシビリティを確認する
- 実機幅、主要ブラウザ、キーボード、画像、読み込みを確認する
- CMS編集者が壊しにくい入力構造にする
- 公開、移行、リダイレクト、バックアップ、復元を計画する

### 5. プラットフォームの制約を理解する

- WordPress: ブロック／クラシックテーマ、テンプレート、投稿タイプ、権限、更新、バックアップ
- ECモール: 使用可能なHTML・画像・外部リンク、カテゴリ、審査、キャンペーン、媒体別仕様
- STORES等: 商品、カテゴリ、在庫、配送、決済、税、特商法表示、通知、テスト
- Shopify等: 商品とバリエーション、コレクション、テーマ複製、Liquid、アプリ影響
- STUDIO／Webflow: CMS構造、公開、SEO設定、フォーム、プラン・権限

管理画面のボタン位置を暗記するより、「商品情報」「表示テンプレート」「決済・配送」「公開状態」がどう関連するかを理解します。

## 参考サイトから読み取るC社の品質

指定された参考サイトは、製造業の強み、設備、製品、納入実績、対応地域、採用情報、問い合わせを明確な区切りで構成しています。「同等のクオリティ」は見た目の模倣ではなく、次の観点へ分解して見積もります。

- 企業の強みを複数の根拠へ分解する情報設計
- 大きな写真と短いコピーによる優先順位
- 製品・設備・実績の反復可能なコンテンツ構造
- PCとモバイルのナビゲーション、余白、文字サイズ
- 問い合わせへの導線
- 更新担当者が追加しやすいCMSフィールド
- 画像撮影・原稿・ロゴなど、発注者から必要な素材

URLだけを見て「7〜10日で可能」と返答せず、ページ数、機能、原稿・写真の準備状況、確認回数、WordPress環境、移行範囲を質問します。

## 基礎講座からの差分

| 基礎講座でできること | 発展講座で追加すること |
|---|---|
| 一つの更新依頼を整理 | 新規・リニューアル案件の全体スコープを定義 |
| HTML/CSSを直接編集 | CMS・ECのデータとテンプレートを設計 |
| 自分の変更を確認 | デザイナー・コーダーへ指示し成果物を受入 |
| 小規模な画像差替え | 撮影計画、商品画像量産、バナー展開 |
| 公開前後を確認 | DNS・移行・リダイレクト・復元・保守を計画 |
| 表示内容を修正 | SEO、購入導線、KPIから改善案を作る |

## 到達レベルの扱い

求人Aの「ディレクション経験3年以上」や各社の「実務経験」は、授業修了だけでは満たしたと表現できません。本講座は、アシスタントディレクター、ジュニアWeb制作者、EC運用補助として実務へ入るための成果物と判断基準を作ります。

応募時は「経験3年」と偽らず、演習案件で担当した範囲、使用ツール、判断、検証、成果物を示します。
