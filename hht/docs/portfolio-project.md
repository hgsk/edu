# 自分のポートフォリオサイト制作

第14・15回は、これまでの仕事で学んだHTML・CSSを使い、自分を紹介する1ページのポートフォリオサイトを作ります。

## だれに見てほしい？

最初に一人だけ思い浮かべましょう。

- 進学先の先生
- インターン先やアルバイト先の担当者
- 家族や友人
- 半年後の自分

「この人に、どんな自分を知ってほしい？」を一文にします。

## 掲載する内容

必須:

1. 自分を表す見出しと短い紹介
2. できるようになったこと
3. カフェサイトの制作実績
4. 制作で工夫したこと、迷ったこと、確認したこと
5. 次に作ってみたいもの

選択:

- 好きな色やデザイン
- 趣味や興味
- 制作途中と完成後の比較
- 授業で覚えた用語の説明

## 載せないもの

- 自宅住所、個人の電話番号、個人メール
- 学校や本人が公開を認めていない氏名・顔写真
- パスワード、接続情報、非公開URL
- 利用してよいか分からない画像・文章
- 実際には担当していない仕事や、できない技術

## 第14回で作るもの

- 見てほしい相手と伝えたいこと
- 掲載内容のメモ
- 紙またはFigmaの簡単なワイヤーフレーム
- [`portfolio/index.html`](../portfolio/index.html)
- 見出し、文章、制作実績、画像と`alt`

## 第15回で作るもの

- [`portfolio/css/style.css`](../portfolio/css/style.css)
- スマートフォンとパソコンに対応したレイアウト
- 必要な場合だけ使う短いCSSアニメーション
- キーボード・文字拡大・画面幅・権利の確認
- 練習用URLへのデプロイ
- 2分間の作品紹介

## 3段階の完成目標

### 最小完成

時間が足りない場合も、ここまでは完成させます。

- 1ページで、自己紹介、できること、カフェサイト実績、次に作りたいものが読める
- 見出しと文章がHTMLで正しく構造化されている
- スマートフォンで横スクロールがない
- 個人情報と画像の利用条件を確認している

### 標準完成

- 自分で選んだ色、文字、余白、カードレイアウトがある
- パソコンとスマートフォンで情報の優先順位が保たれる
- カフェサイトの工夫と確認内容を自分の言葉で説明している
- キーボード、200%拡大、画像と`alt`を確認している

### 発展チャレンジ

- 制作前後の比較、別案、失敗から学んだことを掲載する
- CSSカスタムプロパティやGridを、自分のデザインルールとして使う
- 動きが必要な理由を説明し、`prefers-reduced-motion`へ対応する
- Lighthouseなどの結果をうのみにせず、手動確認と合わせて改善する

## できたかチェック

- [ ] だれに何を伝えるサイトか説明できる
- [ ] 見出しの順番だけで内容が分かる
- [ ] カフェサイトで自分が担当したことを正直に書いた
- [ ] スマートフォンでも横スクロールがない
- [ ] キーボードでリンクを選べる
- [ ] 画像に必要な`alt`がある
- [ ] 個人情報や利用権に問題がない
- [ ] 公開前のバージョンへ戻せる
- [ ] 公開URLで表示を確認した

完成度だけでなく、「なぜこの内容・色・レイアウトにしたのか」を自分の言葉で説明できることを大切にします。
