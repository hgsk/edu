# 新人Webデザイナー お仕事ワークブック

今日からあなたは、架空のカフェ「NORTH LIGHT COFFEE」を担当する新人Webデザイナーです。毎回、お客さまから新しい依頼が届きます。分からないことは質問して大丈夫。必要なHTML・CSSをその場で覚え、最後は自分の言葉で作業を報告しましょう。

授業を始めるときは、毎回このリポジトリのルートをVS Codeで開きます。左側に`README.md`と`hht`が見えること、ソース管理に自分のブランチが表示されていることを確認してから、[学生向け授業入口](../student/README.md)を開きましょう。

![カフェのお客さまから依頼を受け取り、作業内容を考える高校生Webデザイナー](../assets/workbook/01-request-arrives.webp)

## 毎回のお仕事ルート

1. **メールを開く** — 何を頼まれたのか見つける
2. **作戦を立てる** — 直す場所、直さない場所、質問を決める
3. **技を覚える** — 今日の仕事に必要なHTML・CSSを試す
4. **サイトを直す** — 小さく変更し、ブラウザで見る
5. **チェックする** — パソコン、スマートフォン、キーボードで確かめる
6. **返信する** — 変更したこと、確認したこと、まだ分からないことを伝える

各回の星は3つです。完成度だけではなく、質問できたこと、対象外を守れたこと、確認できたことにも星を付けましょう。

**今日のミッション:** 依頼を正しく受け取り、HTMLを公開URLに表示する。最初のバージョンとバックアップを残し、いつでも自習を続けられる環境を作る。

**返信チャレンジ:** 「受け取りました」「練習用URLへ公開しました」「確認したいこと」を3文で書こう。

**星チェック:** □ CCを確認した　□ 公開URLで表示できた　□ 最初の状態へ戻せた　□ 自習の再開手順を説明できた

### 2. 変更とチェック

| ファイル・場所 | 変更前 | 変更後 | 確認結果 |
