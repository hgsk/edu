# 授業レジュメ・シラバス

## 科目名

Webデザイン実習（HTML・CSS）

## 授業時間

- 15回
- 1回120分
- 合計30時間

## 授業の概要

新人Webデザイナーとして架空クライアントのサイト更新を担当し、HTMLとCSSの基礎から、レイアウト、フォーム、レスポンシブデザイン、CSSアニメーション、確認、公開までを実作業の流れで学びます。

指定書籍はHTML・CSSの技術事項を調べる副教材として使用します。授業の中心は、本講座で提示する依頼と制作課題です。JavaScript、DOM、Ajax、jQuery、Vue.jsは別授業で実施し、本科目の評価対象に含めません。

## 到達目標

1. ブラウザとVisual Studio Codeを使い、HTML・CSSを作成・修正できる
2. 内容に合うHTML要素と、再利用可能なclassを選べる
3. Flexbox、Grid、positionを目的に合わせて使用できる
4. フォームをキーボードでも操作できる形で作成できる
5. スマートフォンを含む複数画面幅へ対応できる
6. transitionとkeyframesを目的とアクセシビリティに配慮して使用できる
7. 依頼範囲、影響範囲、承認状態を確認し、安全に公開できる

## 実務経験のある教員等による授業

実務で行われる依頼確認、要件整理、制作、検証、クライアント確認、公開、公開後確認を授業課題として扱います。講師はクライアント役と制作会社の先輩役を担当し、受講者は作業記録と確認依頼を提出します。

## 授業方法

- 60分の「講義10分・ディスカッション20分・ハンズオン30分」を各回2サイクル
- 前半サイクルでHTML・CSS技術、後半サイクルで実務依頼への適用
- 個人でのHTML・CSS実装
- 依頼メールとクライアント確認のロールプレイ
- ブラウザ、開発者ツール、エディター検索による調査
- 自己テストと相互受入テスト
- 模擬公開、講師用SFTP、XServer練習領域

## 評価方法

成績記録は、毎回の提出40%・中間課題20%・最終制作40%を目安にします。ただし本科目の目的は仕事の流れを経験することにあるため、合否は次のどちらか一方を満たせば合格とします。

- **参加ルート:** 授業へ参加し、受注・計画・実装・検証・報告の工程記録を継続的に残す
- **制作ルート:** 出席や毎回提出が不足していても、最終制作と説明で必須ルーブリックを満たす

参加ルートは、出席しているだけで高度な完成度を要求しません。授業中に各工程へ取り組み、記録を残すことを確認します。制作ルートは完成画面だけでなく、依頼整理、変更範囲、検証、公開判断を含めて評価します。

## 教科書・副教材

『これからWebをはじめる人のHTML＆CSS、JavaScriptのきほんのきほん』（ISBN 978-4-8399-5971-5）

使用範囲:

- Chapter 1 Webの開発環境
- Chapter 2 HTMLとCSS
- Chapter 3 スマートフォン対応
- Chapter 4 フォーム部分を必要に応じて参照

対象外:

- Chapter 5 JavaScript
- Chapter 6 DOM・イベントドリブン
- Chapter 7 Ajax・jQuery・Vue.js
- AppendixのNode.js、Sass、TypeScript等

書籍のHTML5.1/CSS3時点の記述は歴史的な説明として扱い、現在の標準やブラウザで異なる箇所は講師資料を優先します。

## 必要な環境

- 学校管理のPCまたは授業用PC
- 最新版の主要ブラウザ
- Visual Studio Code
- 学校が用意した学習用メール環境
- 画像形式変換ができるツール
- 授業用のAI画像生成環境
- 公開演習用の分離された領域

## 履修上の注意

- 実在する個人情報、認証情報、顧客の未公開情報を使わない
- AIやサンプルのコードを理解せず提出しない
- 書籍・サンプル・参考サイトの著作物を自作品として扱わない
- クライアント役の承認前に公開しない
- JavaScriptの質問は別授業との境界を確認して扱う
- メール演習では学習用の架空アドレスだけを使い、個人アドレスや実在顧客へ送信しない
