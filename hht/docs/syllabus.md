# 授業レジュメ・シラバス

## 科目名

Webデザイン実習（HTML・CSS）

## 授業時間

- 15回
- 1回120分
- 合計30時間

## どんな授業？

みなさんは今日から、新人Webデザイナーです。架空のお店から届く「文章を直して」「写真をもっと目立たせて」といった依頼に挑戦します。HTMLとCSSを使って、サイトを直し、確認してもらい、安全に公開するところまで体験します。知識を覚えるだけではなく、実際の仕事に近い流れで学ぶ授業です。

## 授業が終わるころにできること

1. ブラウザとVisual Studio Codeを使って、HTML・CSSを書いたり直したりできる
2. 文章の意味に合うHTMLタグと、使い回しやすいclassを選べる
3. Flexbox、Grid、positionを使って、見やすいレイアウトを作れる
4. キーボードでも使いやすいお問い合わせフォームを作れる
5. パソコンでもスマートフォンでも見やすいページを作れる
6. 見る人に負担をかけないCSSアニメーションを作れる
7. 依頼された場所だけを正しく直し、確認をもらってから安全に公開できる

## 本物の仕事に近い進め方

先生は「サイトの修正を頼むお客さま」と「仕事を助ける先輩」の役を担当します。みなさんは依頼を読み、分からないことを質問し、サイトを直して、きちんと動くか確かめます。最後にお客さまのOKをもらって公開します。

## 1回の授業の進み方

- 「先生の説明10分 → みんなで考える20分 → 自分で作る30分」を2回行います
- 前半はHTML・CSSの新しい技術を試します
- 後半は、お客さまからの依頼にその技術を使います
- 自分で確認したり、クラスメイトに使ってもらったりして、ミスを見つけます
- メールの返信、修正の確認、サイトの公開も練習します

## 成績について

大切なのは、最初から完璧なサイトを作ることではありません。「依頼を読む → 考える → 作る → 確かめる → 伝える」という仕事の流れを経験することです。合格までの道は2つあります。

- **授業参加ルート:** 授業に参加して、考えたことや作業したことを毎回記録する
- **作品完成ルート:** 最後の作品を完成させ、どこをどう直したか自分の言葉で説明する

授業に参加して取り組んだことも、自分の力で作品を仕上げたことも、どちらも学びとして大切にします。成績の記録では、毎回の課題40%・中間課題20%・最後の作品40%を目安にします。

## 必要な環境

- 学校管理のPCまたは授業用PC
- 最新版の主要ブラウザ
- Visual Studio Code
- 学校が用意した学習用メール環境
- 画像形式変換ができるツール
- 授業用のAI画像生成環境
- 公開演習用の分離された領域

## 安全に学ぶための約束

- 本物の名前、住所、パスワード、仕事の秘密は使いません
- AIが作ったコードも、「何をしているコードか」を確かめてから使います
- ほかの人が作った文章・画像・デザインを、自分の作品として提出しません
- お客さま役の先生からOKをもらう前に公開しません
- メール練習では授業用アドレスだけを使い、本物のお客さまには送りません
