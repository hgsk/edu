> ページによって「メニューを見る」ボタンの色や形が違います。同じデザインにそろえられますか？

**今日のミッション:** どのページでも、同じボタンだと分かるようにする。

### 今日やること

1. 下のDAY 3開始ZIPを展開する。元の自分のサイトとは別のフォルダーで練習する。
2. `index.html`・`menu.html`・`about.html` の対象リンクをブラウザで比較する。
3. HTMLとCSSを読み、青・茶色になる指定を探す。採用／上書きされた指定をメモする。
4. 3ページの `class="menu-button"` は使い続け、競合する指定を整理する。本文とリンク先は変えない。
5. 保存・再読み込み後の3ページとリンク先を確認し、修正ファイル・競合メモ・報告を提出する。


- **依頼者／見る人**：店舗責任者の佐藤さん／メニューを探すお客さま
- **困っていること**：同じ「メニューを見る」なのに、色や形が違う
- **変えるところ**：3ページの対象リンクの色・形・内側の余白。共通のclassと外部CSSでそろえる
- **変えないところ**：本文、商品・価格、リンク先、ほかのリンクや見出し
- **完成の目印**：3ページで見た目がそろい、CSSが競合した理由を説明できる

### 言葉と構文の読み方：HTMLの名前とCSSの指定

**CSS（Cascading Style Sheets）**は、どの要素へ、どの見た目を付けるかを書く言語です。カスケードは、複数の指定から採用する値を決める仕組みです。全部を暗記する前に、今日の1つのリンクで確かめます。

#### HTML側：classとidは名前を付ける属性

```html
<a class="menu-button" id="shop-menu" href="menu.html">メニューを見る</a>
```

- **`a`**は移動するリンク。**`href`**は移動先。見た目をそろえてもリンク先はそのままです。
- **`class`（クラス）**は同じ役目に繰り返し付けられる名前。`menu-button`はこの教材で付けた名前で、HTMLの予約語ではありません。付けただけで自動的に緑色にはなりません。
- **`id`（アイ・ディー）**はそのページ内の要素を一意に示す名前。同じページで同じidを繰り返しません。
- `class="menu-button"`の値に`.`は書きません。`id="shop-menu"`の値に`#`も書きません。`.`や`#`は、CSS側で名前の種類を指定するときに使います。
- `class="menu-button featured"`のように、半角空白で区切ると2つのclassを付けられます。

#### CSS側：1つの規則を、記号ごとに読む

```css
.menu-button {
  background: #245746;
  color: #fff;
  padding: 0.75rem 1.1rem;
  border-radius: 0.35rem;
}
```

- **`.menu-button`**はセレクター。「classにmenu-buttonがある要素を選ぶ」です。先頭の**`.`（ドット）**がclassの目印です。
- **`{`と`}`（波かっこ）**は指定をまとめる範囲。「ここからここまでが、その要素への見た目の指定」です。
- **`background`**は背景、**`color`**は文字色、**`padding`**は内側の余白、**`border-radius`**は角の丸みを指定するプロパティ（設定項目）です。
- **`:`（コロン）**は項目名と値の区切り、**`;`（セミコロン）**は1つの指定の終わり。`color: #fff;`は「文字色を白にする」と読みます。1つの「項目名: 値;」を**宣言**と呼びます。
- **`#245746`**は16進数の色の表記。ここでの`#`は値の中にあるので色を表します。セレクターの`#shop-menu`（idを選ぶ）とは場所も役目も違います。
- **`rem`（レム）**は文書の基準文字サイズに対する長さ。`padding`に2値を書くと「上下・左右」の順です。**`px`（ピクセル）**も長さの単位です。`0`以外の長さでは原則として単位も書きます。
- **`/* 補足 */`**はCSSのコメント。ブラウザが見た目の指定として実行しない、人のためのメモです。HTMLのコメントは`<!-- 補足 -->`で、書き方が違います。

#### CSSファイルを読むためのlink

```html
<link rel="stylesheet" href="css/style.css">
```

`head`内の**`link`**は別ファイルとの関係を示す空要素。**`rel="stylesheet"`**はCSSとして読む関係、**`href`**はそのCSSの場所です。画面上の移動リンク`a`とは別です。CSSが効かないときは、この場所と保存先も照合します。

#### 同じ指定が複数あるとき、何が採用される？

- **外部CSS**は`style.css`のような別ファイル。**内部CSS**はHTMLの`<style> ... </style>`内。**インラインCSS**は要素の`style="..."`属性です。今回のメニューページには内部CSSがあります。
- 今日のように同じ出所の通常の指定を比べる場合、**詳細度（しょうさいど）**というセレクターの強さを見ます。`#shop-menu`のようなid指定は`.menu-button`のようなclass指定より強くなります。
- 同じ詳細度でほかの優先条件も同じなら、後に書かれた指定が採用されます。「外部CSSなら常に弱い」というルールではありません。
- **継承**は親要素から子へ文字色などが受け継がれること。すべての項目が継承されるわけではありません。要素自身に指定があれば、継承値よりそちらを使います。
- **`!important`**は通常の指定より優先させる印。今日の課題ではこれを追加して押し切らず、重複する原因を整理します。

**構文で困ったら：** 全角の`：`・`；`・`｛`にしていないか、`;`や`}`を消していないか、class名のつづりが一致するかを確認します。HTMLの属性は`=`、CSSの宣言は`:`です。

### 例を分解して読む：必要な項目から確認する

ここは、今日の実習に出てくる言葉を1つずつ読むための参照欄です。全部を追加する作業一覧ではありません。最初は使う項目だけを読み、つづり・記号・意味・画面の変化を対応させます。実習へ進むときはこの欄の後の手順へ戻ります。

#### 読み取り例：background（バックグラウンド）

**何の言葉？** 背景の色や画像などをまとめて指定する項目です。この例は背景色だけを指定しています。文字の色はcolorで別に決めます。

```css
.menu-button {
  background: #245746;
}
```

**上から順に読むと：** 「.menu-buttonで選ぶ要素に、backgroundという項目を、#245746という値で指定する」です。どの要素を選ぶかと、その要素の何を変えるかを別々に読みます。セレクターとプロパティ名は同じ役目の言葉ではありません。

- `.menu-button`は**対象**です。自分のHTMLにある要素名・class・idと対応するかを先に調べます。見本の名前を写すだけでは、存在しない対象には表示の変化が出ません。
- 開く`{`から閉じる`}`までが、この対象へ書く**規則の本体**です。前後にある別の要素への規則を巻き込まないように、区切りを追います。
- `background`が**プロパティ**、`:`の後の`#245746`が**値**です。項目名と値を逆に書きません。HTMLの属性のように`=`で結ぶ書き方でもありません。
- `;`はこの宣言の終わりです。1つの規則へ次の項目を書くときも、宣言の区切りを保ちます。日本語の本文と違って、記号の種類が読み取りに関わります。

**表示との対応：** 正しく当たる条件なら、対象リンクの背景が教材の基準の緑色になることを確認します。コードにこの行があるというだけでは、最終的にこの値が採用された証拠にはなりません。選んだ要素のStylesで、採用・上書きの状態も対応させます。

**比べると理解しやすいこと：** 背景だけを変えても文字色はそのままなので、背景と文字の組み合わせを比較する。変更は作業用コピーで1項目ずつ行い、見る場所と画面幅をそろえて比較します。変化がなければ、まず元の状態との違いを言葉にします。

**この例で間違いやすいところ：** 青いままならセレクターが当たっているか、id指定などが上書きしていないかを見る。全角記号に変わっていないか、値に必要な単位やかっこが残っているかも確かめます。原因が分からない間に別の場所へ同じ宣言を大量に追加せず、実際の対象と採用元を追います。

**理解の確認：** 「この指定は誰に当たる？」「どの項目を変える？」「画面のどこを見れば分かる？」を、この例の対象・項目・結果の言葉で説明してみましょう。説明のための読解例なので、この規則をそのまま全ページへ追加する課題ではありません。実際に変える範囲は今日の依頼と実習を使います。

### ② 決めて直す：次の変更も1か所で済む形に

**まず編集する場所を開きます。** 次の手順は開始ZIPのコピーに対して行います。

1. `about.html`で`id="shop-menu"`を検索します。次に`css/style.css`で`#shop-menu`を検索し、同じ要素を選んでいることを照合します。
2. `menu.html`の`head`内の`style`を読みます。共通CSSと同じ`.menu-button`に別の背景色・角丸が指定されていることを確認します。
3. 削除・変更前に、①の表へ現在の採用値とファイル名、上書きされた値を記録します。
4. 基準の外部CSSの`.menu-button`を残し、対象ボタンだけの青・茶色の上書き指定を整理します。他のCSS規則までまとめて消さず、HTMLの`href`と本文を保持します。
5. 保存して3ページを再読み込みします。色だけでなくpaddingとborder-radiusの採用値も確認します。

3ページの対象リンクには、すでに `class="menu-button"` が付いています。共通の指定が使われなくなる原因を見つけて、不要な指定を整理します。強い指定を次々と追加する前に、**どの指定を残せば同じ役目のリンクがそろうか**を考えます。

```html
<!-- 同じ役目に、同じ名前。hrefは元のまま -->
<a class="menu-button" href="menu.html">メニューを見る</a>
```

メニューページのリンク先は `#menu-list`（そのページの商品一覧）です。ほかの2ページと同じURLへ書き換える必要はありません。

**残すもの／整理するもの／理由**を1行ずつ書いてから、HTMLと `css/style.css` を修正します。共通CSSが読めているか、各ページの `<link rel="stylesheet" href="css/style.css">` も確認します。

### 用語のヒント

<details>
<summary>class・id・CSSの用語を確認する</summary>

- **class**：同じ役目のものに繰り返し付けられる名前。CSSでは `.名前`
- **id**：ページ内の1つの要素を指す名前。同じページで重複させない。CSSでは `#名前`
- **外部CSS**：HTMLとは別のCSSファイル。複数ページから読める
- **CSSの競合**：同じ要素の同じ項目に、違う値が指定されること
- **padding**：文字とボタンの端の間にある、内側の余白

</details>
