### 言葉と構文の読み方

**ボックスモデル**は、要素の内容・内側の余白（padding）・枠（border）・外側の余白（margin）を区別する考え方です。**ヘッダー／フッター**は上部の案内／末尾情報、**ナビゲーション**は移動リンクのまとまりです。

```css
.nav-list {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}
.nav-list a:focus-visible {
  outline: 3px solid #245746;
}
```

- **`display: flex;`**は子要素を主に1方向へ並べるFlexbox（フレックスボックス）を使う指定。`flex-wrap: wrap;`は入り切らなければ折り返す指定です。
- **`gap`**は並べた要素の間隔。`margin`と`padding`は外側／内側で、同じ余白ではありません。
- **`.nav-list a`**は「nav-listというclassの要素の中にあるa」。間の半角空白は、内側の要素を選ぶ意味です。
- **`:focus-visible`**はキーボード操作などで選択位置の表示が必要な状態を選ぶ疑似クラス。`outline`は輪郭線です。コロンはここではセレクターの一部です。
- **`max-width`**は幅の上限、`width`は幅。`aria-current="page"`はHTMLの属性で、今いるページのリンクを示します。

ここは書き方の説明です。既存ファイルを全部消して貼り替えず、下の実習で対象を確認してから使います。

### 例を分解して読む：必要な項目から確認する

ここは、今日の実習に出てくる言葉を1つずつ読むための参照欄です。全部を追加する作業一覧ではありません。最初は使う項目だけを読み、つづり・記号・意味・画面の変化を対応させます。実習へ進むときはこの欄の後の手順へ戻ります。

#### 読み取り例：margin（マージン）

**何の言葉？** 要素の外側の余白です。この2値は上下0、左右auto。通常のブロックで幅が利用可能な幅より狭い場合、左右autoで中央へ寄せられます。

```css
.site-header {
  margin: 0 auto;
}
```

**上から順に読むと：** 「.site-headerで選ぶ要素に、marginという項目を、0 autoという値で指定する」です。どの要素を選ぶかと、その要素の何を変えるかを別々に読みます。セレクターとプロパティ名は同じ役目の言葉ではありません。

- `.site-header`は**対象**です。自分のHTMLにある要素名・class・idと対応するかを先に調べます。見本の名前を写すだけでは、存在しない対象には表示の変化が出ません。
- 開く`{`から閉じる`}`までが、この対象へ書く**規則の本体**です。前後にある別の要素への規則を巻き込まないように、区切りを追います。
- `margin`が**プロパティ**、`:`の後の`0 auto`が**値**です。項目名と値を逆に書きません。HTMLの属性のように`=`で結ぶ書き方でもありません。
- `;`はこの宣言の終わりです。1つの規則へ次の項目を書くときも、宣言の区切りを保ちます。日本語の本文と違って、記号の種類が読み取りに関わります。

**表示との対応：** 正しく当たる条件なら、幅が制限された箱の左右に空間ができることを確認します。コードにこの行があるというだけでは、最終的にこの値が採用された証拠にはなりません。選んだ要素のStylesで、採用・上書きの状態も対応させます。

**比べると理解しやすいこと：** paddingへ0 autoと書いても同じ指定にはならず、paddingはautoを受け取らない。変更は作業用コピーで1項目ずつ行い、見る場所と画面幅をそろえて比較します。変化がなければ、まず元の状態との違いを言葉にします。

**この例で間違いやすいところ：** 中央にならないときは箱の幅と親の幅が同じでないか、displayや配置の条件を見る。全角記号に変わっていないか、値に必要な単位やかっこが残っているかも確かめます。原因が分からない間に別の場所へ同じ宣言を大量に追加せず、実際の対象と採用元を追います。

**理解の確認：** 「この指定は誰に当たる？」「どの項目を変える？」「画面のどこを見れば分かる？」を、この例の対象・項目・結果の言葉で説明してみましょう。説明のための読解例なので、この規則をそのまま全ページへ追加する課題ではありません。実際に変える範囲は今日の依頼と実習を使います。

#### 読み取り例：現在ページの目印 — a

**何の言葉？** aria-currentは複数の関連項目のうち現在の項目を示す属性です。pageは現在ページ。この教材では各ページの自分自身を指すリンクに付けます。

```html
<a href="about.html" aria-current="page">店舗案内</a>
```

**まず外側を読む：** `<`から最初の`>`までが開始タグです。`a`という名前で、このまとまりの役目をブラウザへ伝えています。見た目の色や大きさをここで直接決めるとは限りません。CSSのセレクターから選ばれ、見た目が付く場合もあります。

- **`href="about.html"`**は、属性名`href`と値`about.html`の組です。`=`は両者の区切り、前後の半角の二重引用符は値の範囲。属性は開始タグの`>`より前へ置きます。
- **`aria-current="page"`**は、属性名`aria-current`と値`page`の組です。`=`は両者の区切り、前後の半角の二重引用符は値の範囲。属性は開始タグの`>`より前へ置きます。

**どこまでが1つ？** `</a>`はこの要素の終了です。開始と同じ名前を使い、先頭に`/`を付けます。開始と終了の間の内容が、この要素のまとまりです。 見本に内容の位置を示すコメントがある場合は、コメント自体を提出する文章として使う意味ではありません。元のファイルのどの内容を残すかを、依頼に合わせて確かめます。

**画面と照合する：** 現在いるページのリンクを区別できることを確認します。設定用の要素は本文画面へ直接文字が出ない場合もあるので、要素の目的に合う場所を見ます。画面上で変化がないことと、HTMLに役目がないことは同じではありません。

**この例で間違いやすいところ：** 3ページ全部の同じリンクへ固定して付けず、ページごとに正しい位置かを見る。属性の値をタグの外へ書いたり、本文と設定をまとめて書き換えたりしないようにします。変更前を残すと、どの記号や文字を変えたか比べられます。

**HTMLとして読む順序：** 最初に要素名、次に開始タグの属性、次に内容、最後に終了を読みます。内側に別の要素があれば同じ順序を繰り返します。字下げをそろえるのは、この囲む関係を見つけやすくするためです。画面で改行されるかどうかは、要素とCSSの表示の指定も関係します。

**理解の確認：** 「何の役目の要素か」「値や本文はどこか」「どの場所で結果を確かめるか」を、この例を指しながら説明してみましょう。読み方を理解するための見本であり、既存ページをこの短い例だけで置き換える課題ではありません。使うファイルと変更範囲は今日の実習の案内を優先します。
