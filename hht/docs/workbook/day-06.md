### 言葉と構文の読み方

**カード**は1商品の画像・名前・説明・価格をまとめた表示です。**Grid（グリッド）**は行と列、**Flexbox**は主に1方向の並びを組む仕組みです。どちらでも実現できる配置があります。

```css
.menu-grid {
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));
  gap: 1rem;
}
```

- **`grid-template-columns`**は列の幅を決める項目。値の**`repeat(2, ...)`**は「後ろの指定を2回繰り返す」。丸かっこは関数の引数、`,`は引数の区切りです。
- **`minmax(0, 1fr)`**は列の最小・最大の幅。**`fr`**は残りの空間を分ける単位。同じ`1fr`が2つなら均等に分けます。
- この例は2列の読み方です。小さい画面では1列へ切り替えます。[DAY 10](day-10.md#day-10)のメディアクエリーは条件でCSSを変える書き方です。
- `grid-template-columns`はカード1枚でなく、カードを囲む親（教材の`.menu-grid`）へ指定します。

ここは書き方の説明です。既存ファイルを全部消して貼り替えず、下の実習で対象を確認してから使います。

### 例を分解して読む：必要な項目から確認する

ここは、今日の実習に出てくる言葉を1つずつ読むための参照欄です。全部を追加する作業一覧ではありません。最初は使う項目だけを読み、つづり・記号・意味・画面の変化を対応させます。実習へ進むときはこの欄の後の手順へ戻ります。

#### 読み取り例：grid-template-columns（グリッド・テンプレート・カラムズ）

**何の言葉？** Gridの列を2本作り、それぞれに残り空間の1割合を割り当てます。親にdisplay:gridがあることが前提です。カード自身の内容の並びとは別です。

```css
.menu-grid {
  grid-template-columns: repeat(2, 1fr);
}
```

**上から順に読むと：** 「.menu-gridで選ぶ要素に、grid-template-columnsという項目を、repeat(2, 1fr)という値で指定する」です。どの要素を選ぶかと、その要素の何を変えるかを別々に読みます。セレクターとプロパティ名は同じ役目の言葉ではありません。

- `.menu-grid`は**対象**です。自分のHTMLにある要素名・class・idと対応するかを先に調べます。見本の名前を写すだけでは、存在しない対象には表示の変化が出ません。
- 開く`{`から閉じる`}`までが、この対象へ書く**規則の本体**です。前後にある別の要素への規則を巻き込まないように、区切りを追います。
- `grid-template-columns`が**プロパティ**、`:`の後の`repeat(2, 1fr)`が**値**です。項目名と値を逆に書きません。HTMLの属性のように`=`で結ぶ書き方でもありません。
- `;`はこの宣言の終わりです。1つの規則へ次の項目を書くときも、宣言の区切りを保ちます。日本語の本文と違って、記号の種類が読み取りに関わります。

**表示との対応：** 正しく当たる条件なら、一覧が2列で並ぶことを確認します。コードにこの行があるというだけでは、最終的にこの値が採用された証拠にはなりません。選んだ要素のStylesで、採用・上書きの状態も対応させます。

**比べると理解しやすいこと：** 1frだけなら1列になるので、同じ商品数で行数の違いを比較する。変更は作業用コピーで1項目ずつ行い、見る場所と画面幅をそろえて比較します。変化がなければ、まず元の状態との違いを言葉にします。

**この例で間違いやすいところ：** 列が変わらないときは、親のGrid指定とメディアクエリーによる上書きを見る。全角記号に変わっていないか、値に必要な単位やかっこが残っているかも確かめます。原因が分からない間に別の場所へ同じ宣言を大量に追加せず、実際の対象と採用元を追います。

**理解の確認：** 「この指定は誰に当たる？」「どの項目を変える？」「画面のどこを見れば分かる？」を、この例の対象・項目・結果の言葉で説明してみましょう。説明のための読解例なので、この規則をそのまま全ページへ追加する課題ではありません。実際に変える範囲は今日の依頼と実習を使います。
