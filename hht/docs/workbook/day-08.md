### 言葉と構文の読み方

**通常フロー**は要素を自然な順番に配置する仕組み。**固定表示**はスクロールしても特定の位置に置くことです。便利でも他の内容を隠すことがあります。

```css
.hours-panel {
  position: sticky;
  top: 1rem;
}
```

- **`position`**は配置の仕組みを指定する項目。**`sticky`**は通常の位置から、スクロール中に指定位置へ張り付く値。**`top`**は上からの位置です。
- **`fixed`**は通常は画面を基準に固定し、元の場所の空間を保ちません。stickyとは別の動きです。
- **`z-index`**は重なる順番に関わる項目。大きな数を付ければ全問題が解決するわけではありません。
- **`overflow`**は内容が領域をはみ出した場合の扱い。祖先のoverflow指定はstickyの挙動にも関係します。
- **`.hours-panel`**は読み方の例の名前。自分の店舗案内の実際のclassを調べてから、その要素へ指定します。

ここは書き方の説明です。既存ファイルを全部消して貼り替えず、下の実習で対象を確認してから使います。

### 例を分解して読む：必要な項目から確認する

ここは、今日の実習に出てくる言葉を1つずつ読むための参照欄です。全部を追加する作業一覧ではありません。最初は使う項目だけを読み、つづり・記号・意味・画面の変化を対応させます。実習へ進むときはこの欄の後の手順へ戻ります。

#### 読み取り例：position（ポジション・スティッキー）

**何の言葉？** 通常の流れの場所を保ちつつ、スクロールに応じて指定の位置へ張り付きます。親やスクロール領域の条件に影響されます。

```css
.hours-panel {
  position: sticky;
}
```

**上から順に読むと：** 「.hours-panelで選ぶ要素に、positionという項目を、stickyという値で指定する」です。どの要素を選ぶかと、その要素の何を変えるかを別々に読みます。セレクターとプロパティ名は同じ役目の言葉ではありません。

- `.hours-panel`は**対象**です。自分のHTMLにある要素名・class・idと対応するかを先に調べます。見本の名前を写すだけでは、存在しない対象には表示の変化が出ません。
- 開く`{`から閉じる`}`までが、この対象へ書く**規則の本体**です。前後にある別の要素への規則を巻き込まないように、区切りを追います。
- `position`が**プロパティ**、`:`の後の`sticky`が**値**です。項目名と値を逆に書きません。HTMLの属性のように`=`で結ぶ書き方でもありません。
- `;`はこの宣言の終わりです。1つの規則へ次の項目を書くときも、宣言の区切りを保ちます。日本語の本文と違って、記号の種類が読み取りに関わります。

**表示との対応：** 正しく当たる条件なら、スクロール途中で案内が上部に残ることを確認します。コードにこの行があるというだけでは、最終的にこの値が採用された証拠にはなりません。選んだ要素のStylesで、採用・上書きの状態も対応させます。

**比べると理解しやすいこと：** fixedと比べると、元の場所の空間と止まる範囲が異なる。変更は作業用コピーで1項目ずつ行い、見る場所と画面幅をそろえて比較します。変化がなければ、まず元の状態との違いを言葉にします。

**この例で間違いやすいところ：** topの指定、親の高さ、祖先のoverflowを調べる。全角記号に変わっていないか、値に必要な単位やかっこが残っているかも確かめます。原因が分からない間に別の場所へ同じ宣言を大量に追加せず、実際の対象と採用元を追います。

**理解の確認：** 「この指定は誰に当たる？」「どの項目を変える？」「画面のどこを見れば分かる？」を、この例の対象・項目・結果の言葉で説明してみましょう。説明のための読解例なので、この規則をそのまま全ページへ追加する課題ではありません。実際に変える範囲は今日の依頼と実習を使います。
