### 言葉と構文の読み方

**hover（ホバー）**はマウスポインターが乗った状態。**focus（フォーカス）**はキーボードなどの操作対象になった状態。**transition（トランジション）**は値の変化を時間をかけて見せる指定です。

```css
.menu-button {
  transition: background-color 0.2s ease;
}
.menu-button:hover,
.menu-button:focus-visible {
  background-color: #173b30;
}
```

- **`background-color 0.2s ease`**は「背景色を0.2秒で、変化の速さをなだらかにして切り替える」。`s`は秒です。
- **`,`**で区切った2つのセレクターへ同じ指定が適用されます。ここではhoverとfocus-visibleの両方です。
- **差し戻し**は確認した人からの修正依頼。指摘番号と変更・再確認を対応させます。OK済みの部分までまとめて作り直しません。

ここは書き方の説明です。既存ファイルを全部消して貼り替えず、下の実習で対象を確認してから使います。

### 例を分解して読む：必要な項目から確認する

ここは、今日の実習に出てくる言葉を1つずつ読むための参照欄です。全部を追加する作業一覧ではありません。最初は使う項目だけを読み、つづり・記号・意味・画面の変化を対応させます。実習へ進むときはこの欄の後の手順へ戻ります。

#### 読み取り例：transition（トランジション）

**何の言葉？** 背景色が変わるときの途中を0.2秒で補間します。easeは速さの変化です。transition自体は変更後の色を指定しないので、状態別の規則と組み合わせます。

```css
.menu-button {
  transition: background-color 0.2s ease;
}
```

**上から順に読むと：** 「.menu-buttonで選ぶ要素に、transitionという項目を、background-color 0.2s easeという値で指定する」です。どの要素を選ぶかと、その要素の何を変えるかを別々に読みます。セレクターとプロパティ名は同じ役目の言葉ではありません。

- `.menu-button`は**対象**です。自分のHTMLにある要素名・class・idと対応するかを先に調べます。見本の名前を写すだけでは、存在しない対象には表示の変化が出ません。
- 開く`{`から閉じる`}`までが、この対象へ書く**規則の本体**です。前後にある別の要素への規則を巻き込まないように、区切りを追います。
- `transition`が**プロパティ**、`:`の後の`background-color 0.2s ease`が**値**です。項目名と値を逆に書きません。HTMLの属性のように`=`で結ぶ書き方でもありません。
- `;`はこの宣言の終わりです。1つの規則へ次の項目を書くときも、宣言の区切りを保ちます。日本語の本文と違って、記号の種類が読み取りに関わります。

**表示との対応：** 正しく当たる条件なら、hoverやfocus時に色が短くなだらかに変わることを確認します。コードにこの行があるというだけでは、最終的にこの値が採用された証拠にはなりません。選んだ要素のStylesで、採用・上書きの状態も対応させます。

**比べると理解しやすいこと：** hover側だけへtransitionを書くと戻るときの挙動が違う場合があるので通常状態へ置く。変更は作業用コピーで1項目ずつ行い、見る場所と画面幅をそろえて比較します。変化がなければ、まず元の状態との違いを言葉にします。

**この例で間違いやすいところ：** 何も変わらないときは背景色の変更規則と採用セレクターを確認する。全角記号に変わっていないか、値に必要な単位やかっこが残っているかも確かめます。原因が分からない間に別の場所へ同じ宣言を大量に追加せず、実際の対象と採用元を追います。

**理解の確認：** 「この指定は誰に当たる？」「どの項目を変える？」「画面のどこを見れば分かる？」を、この例の対象・項目・結果の言葉で説明してみましょう。説明のための読解例なので、この規則をそのまま全ページへ追加する課題ではありません。実際に変える範囲は今日の依頼と実習を使います。

#### 読み取り例：transform（トランスフォーム）

**何の言葉？** 要素の見た目の位置などを変換します。この例は押している間に縦へ1pxずらします。通常の並びの場所を押し下げるmarginの変更とは違います。

```css
.menu-button:active {
  transform: translateY(1px);
}
```

**上から順に読むと：** 「.menu-button:activeで選ぶ要素に、transformという項目を、translateY(1px)という値で指定する」です。どの要素を選ぶかと、その要素の何を変えるかを別々に読みます。セレクターとプロパティ名は同じ役目の言葉ではありません。

- `.menu-button:active`は**対象**です。自分のHTMLにある要素名・class・idと対応するかを先に調べます。見本の名前を写すだけでは、存在しない対象には表示の変化が出ません。

- `transform`が**プロパティ**、`:`の後の`translateY(1px)`が**値**です。項目名と値を逆に書きません。HTMLの属性のように`=`で結ぶ書き方でもありません。

**表示との対応：** 正しく当たる条件なら、押している間だけ少し下がって見えることを確認します。コードにこの行があるというだけでは、最終的にこの値が採用された証拠にはなりません。選んだ要素のStylesで、採用・上書きの状態も対応させます。

**比べると理解しやすいこと：** 大きな移動や長い動きは操作の邪魔になる場合があり、目的に合う最小限と比較する。変更は作業用コピーで1項目ずつ行い、見る場所と画面幅をそろえて比較します。変化がなければ、まず元の状態との違いを言葉にします。
