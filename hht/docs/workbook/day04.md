**今回の課題:** 初めて来る人が「いつ開いている？

を見つけられるようにします。

- **依頼者／見る人**：店舗責任者の佐藤さん／初めて来店するお客さま

- **変えないところ**：本文の言葉、営業時間、定休日、住所、商品情報、CSS、リンク先
- **完成の目印**：見出しで情報を探せる。  
  `main`は1つ。  
  本文を変えずに整理できた

> **授業用に確認済みの仕様：** 時間と場所を店舗紹介より先に見せます。  
> 見出しと「定休日」「住所」などの項目名は追加・変更してよいものとします。  
> 時間・住所・紹介文など、本文の情報は書き換えません。

1. 下の開始画面で、時間・休み・住所を探します。

この例では、時間・場所・紹介を上から並べています。  
色や写真の仕上げは後で考えます。

### ② 選んで直す：まとまりに役目を付ける

- **`main`**：ページの中心。  
  店舗案内の中心内容を1つにまとめる。
- **`section`**：同じ話題のまとまり。  
  時間、場所、店舗紹介を見出しと組にする。
- **`h1`**：ページの題名。  
  今回は「店舗案内」。
- **`h2`**：各まとまりの見出し。  
  「営業時間」「アクセス」など。

上部の `header`（ページの案内）、`nav`（ページ移動）、下部の `footer`（末尾情報）は、開始データにあります。  
今回はそのまま使います。  
**タグを全部使うことが目的ではありません。**

```html
<!-- まとまりの書き方の例。ここに既存の本文を移す -->
<section>
  <h2>アクセス</h2>
  <p>北海道札幌市北区北00条西0丁目（架空）</p>
</section>
```

同じ話題の見出しと本文がまとまるよう、元の内容を移します。  
タグを変えるときは、開始タグと終了タグを組で確認します。  
見出しの大きさではなく、**ページの題名→各話題**の関係で `h1`・`h2` を選びます。

**判断メモ：** 「＿＿を先にした。  
＿＿を1つのまとまりにした。  
見る人が＿＿を探すため。」

#### sectionとdiv：見た目は同じにできる。役目は違う

**`section`（セクション）と`div`（ディビジョン）は、今回のようなまとまりでは置き換え可能です。  
ただし、意味まで同じになるわけではありません。  
**

| 選ぶタグ | 伝える役目 | 選ぶ場面 |
|---|---|---|
| `section` | 1つの話題のまとまり | 「営業時間」「アクセス」など、見出しを付けて説明する部分 |
| `div` | 特定の意味を持たないまとまり | CSSで横並びにする、背景を付けるなどのためにまとめる部分 |

**HTMLは内容の役目を伝え、CSSは色・余白・配置などのデザインを決めます。**  
`section`は「四角く囲む」「横に並べる」というデザインの指定ではありません。  
同じCSSを使えば、`div`でも同じ見た目にできます。

![lessons/04/tag-comparison.htmlの実画面（赤い番号は教材用の注釈）。  
1はsectionの枠、2はdivの枠、3はタグ名のCSSによる違い](../../assets/workbook/targets/day04-tags.png)

**見る場所（画像の番号と対応）:**

- **① 左上の枠**：`section.info-card`で表示した営業時間です。
- **② 右上の枠**：`div.info-card`で表示した営業時間です。  
  ①と色・枠・余白が同じでも、HTMLの役目は同じではありません。
- **③ 下段の2つの枠**：タグ名を指定したCSSの比較です。  
  左の`section`だけ背景が青くなる理由を、比較ページのCSSと照合します。

[この比較ページを開く](../../lessons/04/tag-comparison.html)。  
上の2つの枠は同じ `.info-card` を使用。  
下の例はタグ名を指定したCSSがあるため、タグを替えると見た目も変わります。

```html
<!-- 話題としてまとめる -->
<section class="info-card">
  <h2>営業時間</h2>
  <p>10:00〜19:00</p>
</section>

<!-- 特定の役目を付けずにまとめる -->
<div class="info-card">
  <h2>営業時間</h2>
  <p>10:00〜19:00</p>
</div>
```

**置き換えるときの確認：**

- 開始タグと終了タグを両方替える。  
  本文、class、id、リンク先は理由なく変更しない。
- CSSに `section { ... }` や `main > section` があると、`div`へ替えた部分にそのCSSは当たらなくなる。  
  同じ見た目を保つには、必要な指定を共通classで受けられるか確認する。
- JavaScriptにもタグ名を指定した処理があれば、対象が変わる。  
  今回の店舗案内にはその処理はない。
- 見出しと本文の関係、ブラウザや読み上げソフトに伝わる役目を確認する。  
  `main`・`nav`や名前付きの`section`を`div`に替えると、役目が自動で同じように伝わるわけではない。
- どこにでも置けるわけではない。  
  たとえば `p`の中に`section`や`div`は入れない。  
  置く場所と中身の条件を確認する。

**「デザインを指定するタグではない」と「替えても必ず見た目が同じ」は別です。**  
ブラウザには最初から用意されたCSSもあり、タグによって初期の見た目が違う場合があります。  
保存後に再読み込みし、表示も確認します。

#### ほかにも、同じ見た目にできるタグはある？

次は**見た目を同じにできても、意味は等価ではない**例です。  
タグは色や形でなく、内容の役目で選びます。  
この表は必要なときに読むヒントです。  
今、全種類を覚える必要はありません。

| 比較するタグ | 意味の違い・置き換えの注意 |
|---|---|
| `article` と `div` | `article`は単独でも成り立つ記事など。`div`にするとその役目がなくなる |
| `nav`・`main` と `div` | ページ移動・中心内容という役目がある。`div`で同じ配置を作れても、役目は同じにならない。今回の`main`を消さない |
| `strong` と `b` | 初期表示はどちらも太字になりやすい。`strong`は重要性、`b`は重要性を加えず注意を引く部分。太くするだけならCSS |
| `em` と `i` | 初期表示はどちらも斜体になりやすい。`em`は強調、`i`は専門用語や別の声・調子など。斜めにするだけならCSS |
| `time` と `span` | 同じ文字を表示できる。`time`は日付・時刻を表し、`datetime`で機械にも値を伝えられる。`span`にはその意味や専用属性がない |

`a`と`button`は同じ形にできても、リンク移動と操作という機能が違います。  
`h2`と`div`も、同じ文字サイズにできても見出しとしての役目が違います。  
**見た目が似ているからといって、どのタグでも自由に交換できるわけではありません。**

### 用語のヒント（必要なときだけ）

**用語の説明**

- **セマンティックHTML**：見た目だけでなく、内容の役目に合うタグを選ぶこと
- **`div`**：特定の意味を持たないまとまり
- **`article`**：単独でも内容が成り立つ記事など。  
  今回、無理に追加しなくてよい
- **`aside`**：中心内容に関係する補足。  
  来店に必要な時間・住所を機械的に補足扱いにしない
- **`dl`・`dt`・`dd`**：項目名と説明の組。  
  「営業時間」とその時間など。  
  使わなくても、役目が伝わる構造ならよい
