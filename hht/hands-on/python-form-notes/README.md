# フォームをPythonで受け取り保存する追加実習

[DAY 11のフォーム追加課題](../../docs/workbook/day-11.md#python-form)が、依頼・準備・操作・完成条件・提出物の正本です。[テンプレート追加課題](../../docs/workbook/day-11.md#python-template)の続きとして取り組みます。

- `starter/`：作業場所へコピーする開始データ。
- `tests/`：学生・講師共通の確認。
- `instructor/`：進行メモと正解例。学生へ画面共有しません。

架空の商品メモだけをlocalhostで扱います。外部公開や実サイトへの送信はしません。
