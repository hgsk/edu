# Pythonで店舗案内を生成する追加実習

学生向けの依頼・準備・手順・完成条件の正本は、[DAY 11の選択追加課題](../../docs/legacy-workbook/day11.md#python-template)です。基本15回を進めるための必須課題ではありません。

- `starter/`：本人の作業場所へコピーする開始データ。正解は含みません。
- `tests/`：学生・講師が同じように使うローカル確認スクリプト。
- `instructor/`：講師用の進行メモと正解例。学生へ画面共有しません。

新しいアカウントや公開先は使いません。生成したHTMLはローカルで開きます。
