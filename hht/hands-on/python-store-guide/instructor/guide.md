# Python店舗案内 進行・検証

課題条件は[DAY 11の正本](../../../docs/workbook/day-11.md#python-template)だけで管理します。基本15回の必須条件や全体の合格ルートへ追加しません。Python未導入者には準備済みの学校PCを用意してください。

依頼・影響範囲確認10分、Pythonの文字列・辞書・リストと3つの役割20分、準備・開始状態20分、実装30分、検証と報告20分を目安にします。初学者の所要時間は未実測です。途中のデータ変更だけでは表示が変わらない場面と、HTMLだけの修正が再生成で消える場面で理由を聞きます。

`solution/`には学生が変更する2ファイルだけを置いています。検証用の別コピーへ`starter/`をコピーし、その上に`solution/`の`data.py`と`templates/index.html`を重ねてください。学生の作業ファイルを正解で上書きしません。

リポジトリルートで、課題依存を導入したPythonから次を実行できます。

```text
python hht/scripts/verify_python_exercises.py
```

このコマンドはPythonの3つの追加課題の正解例を一時コピーで検査し、未完成スターターが検査で失敗することも確かめます。提出物の画面・説明・対象外の保持は講師が別にレビューします。
