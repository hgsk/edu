# 夏祭りサイト 新年度版制作ハンズオン

前年版のイベントサイトと新年度の企画資料を比べ、2027年度版へ更新する120分の実務ハンズオンです。

## 学ぶこと

- 企画資料から変更点と未確定事項を見つける
- 年・日付・時刻・会場・リンクを影響範囲まで更新する
- 音楽ステージのタイムテーブルを読みやすくHTML化する
- 学校協賛を主催者と混同しないよう表示する
- CSSでスマートフォン対応と情報の優先順位を整える
- 構造化データ、アクセシビリティ、公開前確認まで行う

## 学生向け

1. [企画資料](./student/project-brief.md)を読む
2. [ワークブック](./student/workbook.md)に作戦を書く
3. [`starter/`](./starter/)を自分の作業場所へコピーする
4. `index.html`と`css/style.css`を編集する
5. チェックとクライアントへの確認文まで作る

基本課題のあと、[追加実務ミッション](./student/extension-missions.md)から授業時間に合わせて選択します。

- 曖昧な依頼の要件定義
- 出演者紹介ページのワイヤーフレーム
- スマートフォン・アクセシビリティ改善
- SEO・速度・リンク・HTML品質確認
- デザイナー／コーダーへの指示、公開計画、引き継ぎ
