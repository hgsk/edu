# 講師用 追加ミッション運用ガイド

## 使い方

追加ミッションは基本ハンズオン120分の外側にあります。15回・30時間の授業で使う場合は、ほかの課題と差し替えるか、複数回に分けてください。

| 学習状況 | 推奨ミッション |
|---|---|
| HTML/CSSを学び始めた | 2、3 |
| サイト更新を経験した | 1、4 |
| 就職・実務を意識する | 1、5 |
| Webディレクターを目指す | 1、5 |
| Webデザイナーを目指す | 2、3、4 |

## 共通評価

各4点、合計20点です。

| 観点 | 4点の状態 |
|---|---|
| 依頼理解 | 確定・未確定・要確認を分けている |
| 影響範囲 | 複数ページ、属性、データ、公開後まで確認している |
| 制作品質 | HTML/CSS、スマホ、アクセシビリティが要件を満たす |
| 検証 | 目視とツールの両方で根拠を残している |
| 報告 | 変更、未変更、未確定、次の行動を他者へ渡せる |

## 講師が答えを与えすぎない問い

- その情報は資料で確定していますか？
- その変更は別のページにもありませんか？
- 見た目以外に、HTMLの属性やデータにもありませんか？
- そのリンクを初めて見る人は、移動先を予想できますか？
- 公開後に問題があったら、どの状態へ戻しますか？
- 次年度の担当者は、どこを見れば更新できますか？

## ミッション別の注意

- **1:** 質問数ではなく、回答が制作判断へつながるかを見る。
- **2:** 未支給の出演者情報や写真を創作させない。
- **3:** Lighthouse点数だけでアクセシビリティ合格にしない。
- **4:** ツールを実行した事実ではなく、原因の説明と再確認を見る。
- **5:** 指示書に対象、完成条件、確認者、戻す方法があるかを見る。
