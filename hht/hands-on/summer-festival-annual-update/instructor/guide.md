# 講師用 進行ガイド・想定変更一覧

このファイルには課題の判断材料が含まれます。学生へ最初から見せないでください。

## 位置づけ

- 所要時間: 120分
- 推奨時期: 第10回終了後、または第11〜13回の統合演習として差し替え
- 前提: HTML構造、class、Flexbox/Grid、レスポンシブ、開発者ツール、バックアップを経験済み
- 評価対象: 読解、影響範囲、実装、確認、報告

## 120分進行

| 時間 | 内容 |
|---:|---|
| 5分 | 導入トーク：年号だけ直す仕事に見える？ |
| 10分 | 企画資料を確定・未確定・変更・要確認へ分類 |
| 15分 | 全3ページの共通ナビ、相互リンク、ページ内リンクを先に確認 |
| 15分 | 前年版を検索し、変更範囲を作戦メモへ記録 |
| 40分 | HTML/CSS実装 |
| 20分 | 320／768／1024px、キーボード、読み上げ順の確認 |
| 10分 | 変更点、未確定事項、バックアップ名、確認依頼を作成 |
| 5分 | 振り返りトーク：講師ならどう守って更新するか |

## 冒頭5分の問いかけ

- `2026`を全部`2027`に置換したら完成かな？
- 音楽ステージが増えると、ナビゲーションには何が必要？
- 「学校協賛」と「主催」を同じ場所に書くと、何が伝わってしまう？
- URLとロゴが未支給なら、仮のものを作ってよい？

## 完成に必要な主な変更

- 3ページの共通ナビゲーション、現在地表示、相互リンクを本文制作より先に確定
- Linkinatorの再帰・フラグメントチェックと手動クリック確認を実施
- `title`、description、ロゴ文字、eyebrow、見える開催情報
- 開催日を2027-08-07、開催時間を11:00〜20:30へ更新
- 雨天時の順延日と開催判断時刻を8:00へ更新
- 音楽ステージ用ナビゲーションとセクションを追加
- 6演目を`time`要素または意味の通る一覧で実装
- ステージ終了予定20:15と、順延時変更可能性を掲載
- 学校協賛セクションを主催と分離して追加
- 学校URLは未確定のためリンクを作らず、確認依頼へ記載
- 学校ロゴは未支給のため画像を捏造せず文字掲載
- JSON-LDのname、startDate、endDateを更新
- 新しいステージ部分をオレンジ系で区別
- 320pxで時刻と出演者が重ならないレイアウト
- フッター著作権年は、公開・更新年を示すものとして2027へ更新する判断を説明できる

## 許容する実装

- タイムテーブルは`ol`、`ul`、`dl`のいずれでもよい。読み上げ順と時刻の対応が明確なら合格。
- CSSはGridでもFlexboxでもよい。表を使う場合は見出しセルを適切に設定する。
- イベント紹介のコピーは企画条件を変えなければ提案可。
- 写真は支給されていないため、既存グラデーションを使う。外部画像の無断取得は不可。

## 差し戻しにする例

- 2027年8月7日の曜日を資料と違う曜日に書き換える
- 出演者名・順番・時刻をデザイン都合で変更する
- 未確定の学校URLを検索・推測して公開する
- 学校協賛を主催者として表示する
- 画面だけ更新して`datetime`やJSON-LDが2026のまま
- ステージを目立たせた結果、雨天判断や会場が見つからない

## 最後5分の要点

講師なら、まず企画資料を「確定」「未確定」に分けます。次に同じ情報が画面、属性、構造化データのどこへ重複しているか検索します。楽しい見た目を作る前に、日時・会場・主催・協賛の責任関係を正しくし、最後にスマホと支援技術で確認します。

問いかけは「何を変えた？」だけで終わらせず、「変えなかったものはなぜ？」「決めずに質問へ回したものは？」まで聞いてください。
