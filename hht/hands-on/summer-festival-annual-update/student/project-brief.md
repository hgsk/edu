# 2027 NORTH LIGHT 夏祭り 企画資料

## 依頼

昨年の夏祭りサイトをもとに、2027年度版を制作してください。今年は音楽ステージを新設し、北ハイテクが学校協賛として参加します。

公開前にステージ担当、学校担当、実行委員会の確認を受けるため、未確定事項は勝手に決めず質問として残してください。

## 対象ページ

- `index.html`: ホーム・開催概要
- `program.html`: 催し・音楽ステージ
- `access.html`: 会場・雨天時

初回校閲で全ページを確認できるよう、本文制作より先に3ページ共通のナビゲーションとページ内リンクを完成させてください。どのページから始めても、ほかの2ページへ移動できる状態を保ちます。

## 開催概要

- イベント名: 2027 NORTH LIGHT 夏祭り
- 開催日: 2027年8月7日（土）
- 開催時間: 11:00〜20:30
- 会場: NORTH川リバーサイドパーク
- 入場料: 無料
- 主催: NORTH LIGHT 夏祭り実行委員会
- 学校協賛: 北ハイテク
- 雨天時: 小雨決行。荒天時は8月8日（日）へ順延
- 開催判断: 当日8:00までに公式サイトで発表

## 今年の見せ場

今年は中央広場に音楽ステージを設けます。ページを開いた人が、開催日と会場に続いて「音楽ステージがある」と気づける構成を提案してください。ただし、交通案内や開催判断が見つからなくなるほど演出を強くしないでください。

### 音楽ステージ

| 時刻 | 出演・内容 |
|---:|---|
| 11:30 | オープニング／北ハイテク軽音楽部 |
| 13:00 | NORTHジュニア吹奏楽団 |
| 15:00 | 地元アコースティックデュオ「Polaris」 |
| 17:00 | 高校生バンドショーケース |
| 19:00 | スペシャルライブ「River Notes」 |
| 20:00 | フィナーレ |

- 各演目の間に転換時間があります。
- 出演者名は上記表記を変更しません。
- 音楽ステージは20:15終了予定です。
- 荒天で順延した場合、出演者と時刻が変わる可能性があります。

## 学校協賛の掲載条件

- 表記は「学校協賛　北ハイテク」とする
- 主催者名と同じ並びにせず、協賛セクションを設ける
- 学校名を装飾目的で変形・省略しない
- ロゴ画像が未支給のため、今回は文字で掲載する
- 学校サイトへのリンク先は確認中。URLを推測しない
- 学校協賛は音楽ステージ運営と会場案内を支援する

## デザインの希望

- 高校生と家族が楽しみに感じる、明るく元気な雰囲気
- 昨年の紺色を残し、ステージ部分へ夕焼けのオレンジを加える
- スマートフォンで時刻と出演者を追いやすくする
- 動きをつける場合は控えめにし、動きを減らす設定へ対応する
