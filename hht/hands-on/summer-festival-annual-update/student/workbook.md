### Tips: ツールでリンク切れを探す

目でクリックしたあと、VS Codeのターミナルで次を実行します。

```powershell
npx --yes linkinator hht/hands-on/summer-festival-annual-update/starter --recurse --check-fragments
```

`ERROR`が出たら、表示されたページとURLを開き、ファイル名、相対パス、`id`のつづりを確認します。ツールが`OK`でも、リンク名が分かりやすいか、現在地が見えるかは人が確認します。

## 4. 新年度版を実装する（40分）

### HTML

- 開催日・時間・会場を最初の画面で確認できる
- 音楽ステージを見出しと時刻付きの一覧で表す
- `time`要素の`datetime`も更新する
- 学校協賛を主催者と別のセクションにする
- 未支給のロゴや未確定URLを勝手に作らない
- 雨天時と開催判断を見つけやすくする

### CSS

- ステージ部分へオレンジを加え、他の情報と区別する
- 320px程度でも時刻と出演者が重ならない
- キーボード操作時のフォーカスが見える
- アニメーションを使うなら`prefers-reduced-motion`へ対応する
