# 講師向け 授業入口

授業準備と進行の入口です。

## 授業前

1. CodespacesまたはVS Codeでリポジトリのルートを開き、[今日の授業パック](../lessons/README.md)を選ぶ。
2. 依頼、編集対象、提出物と授業の流れを確認する。
3. 受講者の作業場所、練習用公開先、メール環境を確認する。
4. 学生へ見せる資料と講師用資料を分ける。

## 必要な資料

- 進行: [授業パック](../lessons/README.md)・[講師ガイド](../docs/instructor-guide.md)・[講師トークガイド](../docs/instructor-talk-guide.md)・[演習運営手順](../docs/exercise-operations.md)
- DAY 3・4: [内容点検と120分／各90分の進行](./day34-guide.md)（開始ZIP、実画面、図、提出メモ付き）
- DAY 5以降: [DAY 3・4改訂の影響と引き継ぎ](./day5-onward-impact.md)
- Markdown: [記号と表示の比較・GFMの便利な書式](../docs/markdown-format-guide.md)（実画面、チェックリスト、折りたたみの例）
- 評価: [完成条件](../student/assignment-checks.md)・[評価ルーブリック](../docs/rubric.md)・[ZIP回収／講師レビュー](../submissions/local-submission.md)
- Git方針の確認: [履歴照合記録](../docs/submission-policy-history.md)
- 付属アプリ: [受講者向けの解説と遊び方](../docs/app-play-guide.md)（授業前の10分練習・操作早見表付き）
- 追加演習: [夏祭りサイト](../hands-on/summer-festival-annual-update/README.md)・[講師用進行ガイド](../hands-on/summer-festival-annual-update/instructor/guide.md)

## 取り扱いに注意する資料

画面共有には[学生向け入口](../student/README.md)か制作ファイルを表示します。講師トークガイド、`fixtures/emails/`の回答情報、講師用メモなどは学生へそのまま提示しません。

接続先、認証情報、個人別の評価記録はリポジトリへコミットしません。画像の出自と用途は[素材一覧](../fixtures/photographer-delivery/ASSET-MANIFEST.md)で確認します。
