# 講師向け 授業入口

授業準備と進行の入口です。

## 授業前

1. Codespacesでリポジトリのルートを開き、[今日の授業パック](../lessons/README.md)を選ぶ。
2. 依頼、編集対象、提出物と授業の流れを確認する。
3. 受講者の作業場所、練習用公開先、メール環境を確認する。
4. 学生へ見せる資料と講師用資料を分ける。

## 必要な資料

- 進行: [授業パック](../lessons/README.md)・[講師ガイド](../docs/instructor-guide.md)・[演習運営手順](../docs/exercise-operations.md)
- 評価: [完成条件](../student/assignment-checks.md)・[評価ルーブリック](../docs/rubric.md)
- 追加演習: [夏祭りサイト](../hands-on/summer-festival-annual-update/README.md)・[講師用進行ガイド](../hands-on/summer-festival-annual-update/instructor/guide.md)

## 資料の取り扱い

画面共有には[学生向け入口](../student/README.md)か制作ファイルを表示します。`fixtures/emails/`の回答情報や講師用メモは学生に見せません。接続先、認証情報、個人別の評価記録はリポジトリへコミットしません。画像の出自と用途は[素材一覧](../fixtures/photographer-delivery/ASSET-MANIFEST.md)で確認します。
