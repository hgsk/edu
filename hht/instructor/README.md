# 講師向け 授業入口

ここは講師が授業準備と進行に使う入口です。学生へ画面共有するときは、回答や講師用メモが見えないよう、学生向け入口または制作ファイルだけを表示してください。

## 授業前

1. VS Codeでリポジトリのルートを開く。
2. [15回分 授業パック](../lessons/README.md)から今日の回を開く。
3. 導入・振り返りトーク、依頼、添付、編集対象、提出物を確認する。
4. 受講者用ブランチ、練習用公開先、メール環境を確認する。
5. 学生へ見せる資料と、講師だけが見る資料を分けて開く。

## 取り扱いに注意する資料

- `fixtures/emails/`には、学生が質問するまで見せない回答情報が含まれます。
- `fixtures/photographer-delivery/ASSET-MANIFEST.md`には、画像の出自と演習上の扱いが書かれています。
- 接続先、認証情報、個人別の評価記録は、このリポジトリへコミットしません。
- 画面共有へ講師トークの結論や依頼の回答を出したまま、学生に考えさせないよう注意します。
