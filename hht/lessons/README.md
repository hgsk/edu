# 講師向け 15回分授業パック

講師が授業回を選ぶと、その日に必要な資料をまとめて確認できます。依頼の回答や講師トークを含むため、学生にはこのパックを直接案内しません。学生は[学生向け入口](../student/README.md)を使います。

## 毎回の開き方

1. Visual Studio Codeでこのリポジトリのルートを開く。
2. 左側にルートの`README.md`と`hht`が見えることを確認する。
3. ソース管理で自分のブランチと前回からの変更を確認する。
4. 下の一覧から今日の講師用授業パックを開く。

`hht`や`starter-site`だけを別に開かないでください。授業資料、依頼、制作ファイル、バージョン履歴を一つのVS Codeワークスペースで扱います。

| 回 | お仕事 |
|---:|---|
| [01](./01/README.md) | はじめての依頼、デプロイ、バックアップ |
| [02](./02/README.md) | 「創業10年」の文章修正 |
| [03](./03/README.md) | ボタンのデザイン統一 |
| [04](./04/README.md) | 情報を見つけやすい構造へ |
