# 学生向け 授業入口

ここは学生が授業中に使う入口です。毎回、VS Codeでリポジトリのルートを開き、このページから今日の仕事を始めましょう。

## 毎回の始め方

1. VS Code左側に、ルートの`README.md`と`hht`が見えるか確認する。
2. ソース管理で、自分のブランチになっているか確認する。
3. 下の表から今日のDAYを開く。
4. 依頼を読み、作戦を立ててから制作を始める。
5. 最後にチェックと返信まで終わらせる。
