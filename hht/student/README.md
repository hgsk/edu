# 学生向け 授業入口

毎回このページから今日の課題を開きます。

PCのVS Codeで受講する場合は、[VS Codeハンズオン手順](../docs/vscode-hands-on.md)で準備し、毎回同じ教材フォルダーを開きます。  
DAY課題は共通です。

## 毎回の始め方

1. PCのVS Codeで本人用のローカルGitリポジトリのルートを開き、本人のブランチと作業状態を確認する。
2. 下の一覧から今回の課題を開く。
3. 依頼を読む → 計画する → 制作する → 確認する → 返信する。
