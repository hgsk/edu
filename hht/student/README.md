# 学生向け 授業入口

毎回このページから今日の課題を開きます。

初回は[Documentsへクローンする手順](../docs/workbook/common.md#clone-edu)で準備します。  
毎回、教材を更新してから、DAY1〜9の練習またはDAY10以降の同じ作品を開きます。  
操作の練習には[VS Codeハンズオン](../docs/vscode-hands-on.md)を使います。

## 毎回の始め方

1. [共通の開始手順](../docs/workbook/common.md#independent-day-start)で教材を確認・保護・破棄・Pullする。
2. 下の一覧から今回の課題を開く。
3. 本文で指定された場所で制作・確認する。
4. [全DAYのPR提出手順](../docs/workbook/common.md#submission-policy)で成果を残す。

## 全15回の授業

- [DAY 1](../docs/workbook/day01.md#day-1-はじめての依頼メール)：はじめての依頼、デプロイ、バックアップ
- [DAY 2](../docs/workbook/day02.md#day-2-創業10年を直して)：「創業10年」の文章修正
- [DAY 3](../docs/workbook/day03.md#day-3-ボタンのデザインをそろえて)：ボタンのデザイン統一
- [DAY 4](../docs/workbook/day04.md#day-4-お店の情報が見つけにくい)：情報を見つけやすい構造へ
- [DAY 5](../docs/workbook/day05.md#day-5-全ページの上と下をそろえて)：ヘッダーとフッターの統一
- [DAY 6](../docs/workbook/day06.md#day-6-人気メニューを見つけやすくして)：人気メニューのカード
- [DAY 7](../docs/workbook/day07.md#day-7-お問い合わせフォームがほしい)：お問い合わせフォーム
- [DAY 8](../docs/workbook/day08.md#day-8-営業時間を見逃さないようにして)：営業時間を見逃さない配置
- [DAY 9](../docs/workbook/day09.md#day-9-もっとインパクトのある写真に)：ファーストビュー画像
- [DAY 10](../docs/workbook/day10.md#day-10-スマホでボタンが押しにくい)：伝える内容を決め、ベースを作る
- [DAY 11](../docs/workbook/day11.md#day-11-5つの更新依頼を安全に直して)：情報が伝わるベースを完成させる
- [DAY 12](../docs/workbook/day12.md#day-12-動きを整えて差し戻しに対応しよう)：同じ作品で、伝わりにくい所を直す
- [DAY 13](../docs/workbook/day13.md#day-13-カフェサイトを承認公開しよう)：余裕があれば、近くの人に見てもらう
- [DAY 14](../docs/workbook/day14.md#day-14-自分のポートフォリオを企画しよう)：必要なフィードバックを反映する
- [DAY 15](../docs/workbook/day15.md#day-15-ポートフォリオを完成公開しよう)：伝わるページとして仕上げる
