# 提出フォルダーの使い方

各自のブランチで、授業回ごとに次のフォルダーを作ります。

Gitを使わない場合は、本人の継続サイト一式とその回の作業記録・証拠をZIPで提出できます。DAY 3・4は各回の提出メモ、DAY 5以降は下のWORKLOGと確認資料を使います。開始時点のバックアップを残し、提出ZIPを展開してHTML・CSS・画像・リンクを確認します。ブランチやコミットはZIP提出の必須条件ではありません。

```text
submissions/
└─ day-01/
   ├─ WORKLOG.md
   ├─ screenshots/
   └─ evidence/
```

## 必ず提出するもの

- `WORKLOG.md`: 依頼、質問、変更、対象外、確認、未確認、URL、バージョン
- `screenshots/`: 指定された画面幅や操作結果
- `evidence/`: 比較表、校正表、確認メール案など

Git提出では、本人のリポジトリのHTML・CSS本体を`hht/starter-site`または`hht/portfolio`で継続更新し、同じファイルを提出フォルダーへ重複コピーしません。講師はコミット差分と`WORKLOG.md`を対応させて確認します。ZIP提出では、サイト本体もZIPへ含め、開始バックアップとの比較とWORKLOGで確認します。教材原本のファイルを毎回戻す必要はありません。

ファイル名に氏名、メールアドレス、パスワード、接続先を入れません。
