# ゲーム・プログラミングのための基礎数学

中学から高校までの数学を使い、位置、動き、抽選、成長、3Dの姿勢を説明する講座です。行列、クォータニオン、制御、信号処理などは工学への発展として扱います。

**[インタラクティブ教材を開く](./index.html)** · [実画面付き操作ガイド](./guide.html)

`math/index.html` をブラウザで直接開けます。外部ライブラリ、ネット接続、ビルド、サーバーは不要です。各単元の代表的な現象を、入力スライダー、アニメーション、一時停止、再生位置の変更で確かめられます。基礎18単元・応用10課題の本文を収録しています。各課題の全内容を自動実行・採点する機能ではありません。

中学校の正負の数・分数・平方根から始め、割合、方程式、比例・反比例、図形、場合の数、確率、データへ進めます。各単元に用語解説、前提へ戻るリンク、比較する操作例、理由付きの読み取り確認があります。数値計算や工学の応用には学習段階を表示しています。

全28単元に、計算や判断の理由を確かめる演習を設けています。変形条件と解の保持、具体例からの予想・証明・反例、概算・単位・誤差による検算を扱い、選択と理由を記述して解説・評価の観点へ照合できます。手計算と計算機を目的で選び、速さだけを評価しません。

**教材の状態：** HTML・CSS・JavaScriptによる教材。授業回数・時間、ゲームエンジンへの実装演習は未確定です。単元番号は授業回数を表しません。ブラウザのメモ保存と読み取り確認は、提出・単元の合否と独立しています。

## 教材を更新するとき

本文はワークブックを編集し、`python math/scripts/build_lessons.py` を実行して `lessons.js` を更新します。生成ファイルを直接編集しません。

- 本文との一致：`python math/scripts/build_lessons.py --check`
- 生成処理の正常系・失敗系：`python -m unittest discover -s math/scripts -p test_build_lessons.py`
- 数式・特異点・境界値：`node math/scripts/test_models.cjs`
- ゲーム・生活の専用数値テスト：`node math/scripts/test_game_life.cjs`。公式の点数表に基づく数値例、例外、近似の上下界、単位換算と不正入力を再現します。
- 実ブラウザ・画面撮影：Playwrightを利用できる環境で `node math/scripts/verify_browser.cjs`。既存のインストールを使う場合は環境変数 `PLAYWRIGHT_MODULE` にモジュールの絶対パスを指定できます。

ブラウザ検証はローカル専用の一時HTTPサーバーと専用ブラウザを起動し、終了を確認します。記録と実画面は `hht/assets/math/verification.json` と同フォルダーのPNGに保存します。
