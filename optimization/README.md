# 最適化講座：メモリが高価な世界でバイトを運ばない

「メモリは高価である」という一つの視点で、L1キャッシュからCDNまで、全階層の最適化を分野横断で学ぶハンズオン教材です。
各階層で名前を変えて再登場する原理と、キャッシュ、メモ化、オブジェクトプールの統一した採否基準を扱います。

**[目次を開く](./index.html)**

プログラミングの経験がある人を対象にしています。
最適化の手法を個別の裏技としてではなく、データ移動の量、回数、距離の会計として身に付けることを目指します。

**教材の状態：** 全30章の本文が用意されています。
各章は、考え方、ハンズオン、代償と判断、確認、演習で構成されます。
章番号は授業回数を表しません。

**学習内容の正本：** このフォルダーの `docs/course-design.md` です。
この入口には講座の概要と進め方と単元一覧を置き、設計の判断は設計文書へ集約します。

- [講座の目的と設計](./docs/course-design.md)

## 進め方

章番号順に読むことを前提にします。
各章のハンズオンは、自分の環境で測り直すことを想定しています。
時間がない場合は、設計文書で指定したコア履修の章（第1章、第2章、第5章、第9章、第13章、第15章、第17章、第20章、第23章、第28章、第30章）から始めてください。
