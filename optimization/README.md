## 章構成の概要

- **序部：** 仮説とその限界、計測の作法、プログラミングモデルはメモリの嘘と約束。
- **第I部：** チップの中を扱い、レジスタ、キャッシュ、プリフェッチとSIMD、TLBを学びます。
- **第II部：** メインメモリとランタイムを扱い、DRAMとNUMA、アロケーションとプール、データ構造を学びます。
- **第III部：** OSとストレージを扱い、OSのキャッシュ、SSD、データベースを学びます。
- **第IV部：** GPUとAIを扱い、VRAMとHBM、ML推論と学習を学びます。
- **第V部：** ネットワークと分散を扱い、運ぶバイト、分散キャッシュ、配置、フロントエンドを学びます。
- **第VI部：** 惑星規模を扱い、CDN、エッジコンピューティング、クラウドの会計を学びます。
- **第VII部：** プログラミングモデルを扱い、命令型とオブジェクト指向、関数型、所有権、宣言型、並列と分散のモデルを学びます。
- **終部：** 統一採否基準、アンチパターン集、総合演習。

全章の一覧と各章の狙いは、[講座の目的と設計](./docs/course-design.md)を見てください。

## 進め方

単元本文が揃ったら、章番号順に読むことを前提にします。
各章は、コスト感覚、計測ラボ、最適化、裏返しの代償、採否判定の順で進みます。
時間がない場合は、設計文書で指定したコア履修の章から始めてください。
