# Unity操作基礎講座の設計

依頼者は学内展示の担当者、見る人は初めてゲームを触る来場者とします。小さな展示用の操作サンプルを、依頼の確認 → 操作 → 実行確認 → 報告の順に制作します。既存の[講座設計](../../hht/docs/course-design.md)の方針をUnityに適用します。

対象はUnityを初めて操作する受講者です。C#の例は入力・変更できる短さに限定し、プログラミング言語全体の学習は扱いません。36単元は授業回数ではなく学習順です。1単元30〜60分、Timeline・Animator・VFX Graphは60〜90分を目安にします。

ユーザーの依頼にあるScene、MonoBehaviour、2D、Input、Timeline、Animator、3D、uGUI、Gizmo、UI Elements、VFX Graphの11単元に、導入、GameObject／Transform、Prefab、物理、マテリアル、カメラ、ライティング、音、デバッグ、ビルドの10単元を追加します。UI Elementsは現在のUI Toolkitの名称も併記します。

**制作対象：** 専用の教材プロジェクトと各単元の独立したシーン。既存ゲームの変更、外部配信、アカウント作成、有料アセットの購入は対象外です。共通の展示テーマを使いますが、前単元の作業ミスが次へ波及しないようにします。

**正本：** 学習内容、依頼、完成条件、提出物は[学生ワークブックのUnity編](../../hht/docs/workbook/unity.md#unity-course)へまとめます。入口と講師向け資料には条件を複製しません。

**画面資料：** 専用プロジェクトを実際に起動して撮影します。画像は `hht/assets/unity/` に保存し、本文から相対参照します。撮影時のEditor、パッケージ、シーン、撮影段階と検証状態を記録します。画面が確認できなければ該当項目を未完了とします。

**日本語UI：** サンプルの見出し・操作・説明・状態・識別用凡例と独自Editorツールを日本語にします。Noto Sans JPとOFLを同梱し、uGUIはTMP、日本語用TMP Settingsを既定にします。UI Toolkitは同じ元フォントから作ったTextCoreアセットをPanel Text Settingsへ指定します。日本語の改行と狭い画面での収まりも実画面で確認します。Unity標準の部品名・API・アセット名・操作検査のIDは維持します。導入手順の正本はワークブックU16です。

**授業で確認すること：** 冒頭に依頼者、見る人、困りごと、変更範囲、完成条件、不明点を読み合わせます。最後に受講者自身が保存後のシーンを開き直し、何ができたか、何で確認したか、何が残るかを説明します。

**追加範囲：** 各単元の開始・完成サンプルを保存し、U22でUnity CLIによる検査と結果の読み方を扱います。Copilot Agent単元は後回しとし、現在の教材には含めません。

**更新と掲載：** 教材保存を監視するタスク、または既存の教材更新コマンドから全72シーンをWebGLビルドし、ブラウザ検査後に差し替えます。各単元へ開始・完成の実行リンクを置きます。入力と成果物のハッシュをCIで照合し、古いビルドを拒否します。WebGL2非対応のVFX GraphとEditor専用Gizmoは制限を明記し、元シーンを改変せずEditorで確認します。

**識別の配色：** 物体を単元共通の色と明度で分け、Sceneと実行画面に識別子・名前を併記します。凡例の正本は学生ワークブックです。色だけを操作対象の手掛かりにしません。材質の床との比3:1以上と同形物体の明暗差を検査し、描画結果は白黒・色覚シミュレーションでも確認します。UIのボタンは明るい背景と暗い文字にします。

**今回の追加：** U23 Shader GraphでColorプロパティ、Base Colorへの接続、MaterialとRendererの関係を実画面で扱います。開始・完成シーンをWebGLに含めます。U37〜U50の主要機能一覧はワークブックに記載し、制作予定と区別します。ゲームループ・共有状態・セーブ管理とScriptableObjectをU24、保留中のCopilot AgentをU50とします。

**U24の追加範囲：** UnityのPlayer loopとゲームの状態遷移を区別し、SOの設定、実行中のセッション、永続化DTOの寿命を分けます。Rootは1個に限定し、シーンのUI参照を保持しません。保存の検証、一時ファイル、バックアップ、v1からの移行、未来版の保護、ブラウザ同期をサンプルと失敗系検査で扱います。課題条件の正本はワークブックです。

**U25〜U27の追加範囲：** バージョン管理、部品の共有、複数人の統合を分けます。Git＋LFSはローカル共有先と独立した2作業コピーで検証し、実競合と新規cloneからの復元を確認します。unitypackageとUPMは専用の新規プロジェクトで導入を検査します。UVCS・Perforce・SVN・クラウド配信は方式の比較として扱い、未接続サービスの操作成功を示しません。各単元に開始・完成シーンを追加します。

**U28の追加範囲：** RequireComponent／DisallowMultipleComponent、Reset／Awakeのローカル取得、OnValidateの自分の値の検査、型付き外部参照、Prefab内部の参照、依存が壊れた時の停止、別のシーン契約による付け忘れ検出を扱います。開始シーンの参照漏れだけを教材として許容し、完成シーンの不備はCLI・ビルドゲートで拒否します。

**U29の追加範囲：** 物理演算のローコード・サンドボックスを作ります。形状・配置・質量・摩擦・反発をInspectorで調整し、配布する操作用スクリプトでDrop／Reset／傾斜・反発の比較を行います。配置を変えて別の遊びを作ることを課題にし、固定の軌道を再生する実装にしません。

**U30・U31の追加範囲：** グレイボックスで寸法・開口・移動と衝突を検証し、キットバッシュで同じ空間へ配布Prefabの外観を組み合わせます。見た目と当たり判定を分け、素材の出所と利用条件、単位・軸・原点・グリッド、ネストしたPrefabとOverridesを確認します。開始／完成4シーンを作り、中央通路の通過と外観切替を実行検査します。

**U32の追加範囲：** VRoid新規モデルのVRM1.0書き出し、UniVRM固定版の導入、Humanoid・Skinned Mesh Renderer・Animator・標準IKを扱います。開始はIK重み0、完成は1。原本と識別用材質を分離し、表情・Spring Boneの制作とAnimation Rigging実装はこの演習の対象外です。TerrainをU41へまとめ、全50単元を維持します。

**U33・U34の追加範囲：** BGM・操作音・3D環境音をAudio MixerのMusic／SFXへ振り分け、公開音量と距離減衰を比較します。WebGLはグループ音量のみを検証します。フォーリーはKenneyのCC0足音を使い、左右の接地イベント・素材・速度を比較します。独自収録や地面の自動判定は含みません。Audio MixerをU33へ、性能計測と自動テストをU45へまとめ、全50単元を維持します。

**U18の追加範囲：** 既存のUI Toolkit単元に14種類のHUD・画面UIギャラリーを含めます。配置、情報の優先順位、空・無効・エラー状態、キーボードフォーカス、確認とキャンセルを扱います。ゲーム本体や永続保存への接続は別単元とし、単元数は増やしません。

**U35の追加範囲：** UI ToolkitのEditorWindowから、Seed付きの市街配置とTerrainの高さ配列を生成します。道路・建物の間隔、中央の平坦部と外周の起伏、専用TerrainData、所有する生成物だけの再生成、Undo／Redo、保存と再読込を扱います。WebGLは保存済み結果の比較用です。予定のアセット導入・2D制作をU41の環境制作へまとめ、全50単元を維持します。

**U36の追加範囲：** 3DのCollider／Rigidbody、CollisionとTriggerの通知、Layerの衝突組合せ、RaycastのLayerMaskとQueryTriggerInteractionを区別します。専用レイヤーの実行中の変更は終了時に復元。開始は壁もTrigger、完成は壁で停止する比較です。2D物理はU41の発展内容とし、イベント・時間と非同期処理の予定をU38へまとめ、全50単元を維持します。
