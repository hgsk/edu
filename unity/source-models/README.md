# 教材モデルの原本

`CourseAvatar.vroid`はVRoid Studio 2.7.0の新規男性ベースから教材用に作成した編集原本です。サンプルキャラクターや利用者の既存モデルを転用していません。`CourseAvatar.vrm`はそのVRM 1.0書き出しです。作者表記はUnity Courseです。

VRMパブリック・ライセンス1.0と埋込メタデータに従って利用してください。全ユーザー利用可、再配布可、改変版再配布可、クレジット必須、商用利用はpersonalNonProfitです。暴力・性的・政治宗教・反社会／憎悪表現の許可はfalseです。許可を別のモデルへ適用しないでください。

配布シーンはM1 Face／M2 Bodyを別色の教材用URP Unlitへ変更しています。VRM原本は変更していません。Unityプロジェクト内のVRMはこの書き出しの同一コピーです。
