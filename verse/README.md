# UEFN Verse講座


UEFN（Unreal Editor for Fortnite）でゲームの仕組みを作るためのプログラミング言語、Verseを学ぶ講座です。  
デバイスの連携、失敗可能式、非同期処理、永続化、Scene Graphの入口までを12単元で扱います。


**[単元の目次を開く](./index.html)**


プログラミングの経験がある人を対象にしています。  
他の言語との違いを意識しながら読めるよう、C++やPythonとの対比を各単元に入れています。  
コード例はEpic公式の表記（PascalCase）にそろえています。


**教材の状態：** Markdownによる教材です。  
UEFNの実機演習（島への配置と公開）は対象外で、コードの読み書きを中心に学びます。  
単元番号は授業回数を表しません。


**学習内容の正本：** このフォルダーの `docs/lesson01.md` から `docs/lesson12.md` です。  
この入口には単元一覧と進め方だけを置き、本文は各単元へ集約します。

## 進め方


単元は番号順に読むことを前提にしています。  
各単元の最後に「確認」があります。  
コードを写すだけでなく、確認の問いへ自分の言葉で答えられるか確かめてください。


UEFNが手元にある人は、コード例を実際にデバイスへ貼って動かすと理解が早まります。  
なくても、コードを読むだけで最後まで進められます。
