# 第1単元 Verseとは


[目次](../README.md) · [次の単元：第2単元 最初のデバイス](./lesson02.md)


**この単元で学ぶこと：** Verseがどんな言語で、どこで使われ、これからどう広がるのかを説明できるようになります。


## VerseはUEFNの言語です


Verseは、Epic Gamesが作ったプログラミング言語です。  
2023年3月にUEFN（Unreal Editor for Fortnite）と一緒に公開されました。  
UEFNでゲームの仕組みを作るとき、デバイスの基本動作だけでは足りない部分は、すべてVerseで書きます。


Verseで書くのは、たとえば得点の管理、勝敗の判定、ボタンを押したときの連動、プレイヤーごとのデータ保持です。  
見た目や物理演算のような重い処理はエンジン側（C++）が担当し、Verseは「何が起きるか」を決める側です。


## 言語としての特徴


- **静的型付け：** 変数や関数の型が決まっていて、コンパイル時に検査されます。
  型の不一致は実行前にエラーになります。

- **関数論理言語：** 関数型の考え方を土台に、「失敗」を言語の仕組みとして持つ論理型の要素を組み合わせた設計です。

- **不変がデフォルト：** 一度定義した値は書き換わりません。
  変える必要がある値だけを `var` で宣言します。

- **並行処理の組み込み：** 待つ、並べて動かす、といった非同期処理が言語の機能として用意されています。

設計には、関数型言語Haskellの設計者の一人であるSimon Peyton Jonesらが参加しています。  
この血統は、第12単元で他言語との違いとして改めて扱います。


## これからのVerse：UE6との関係


Epicは、Unreal Engine 6（UE6）でVerseをゲームプレイの主言語にする計画を発表しています。  
あわせて、Scene Graphという新しいゲームプレイの枠組みが基盤になります。  
Scene GraphはUEFNで先行して提供が始まっており、この講座の第11単元で入口を扱います。


💡 **ヒント：**

> UE6は発表時点では将来の計画です。  
> ただし、Scene GraphとVerseの組み合わせ自体は、現在のUEFNで実際に触れます。  
> 今UEFNでVerseを学ぶことは、そのまま将来の土台になります。


## Verseのコードを先に見る


詳しい説明は次単元からにします。  
まず全体の見た目だけ確認します。

```verse
using { /Fortnite.com/Devices }
using { /Verse.org/Simulation }
using { /UnrealEngine.com/Temporary/Diagnostics }

hello_device := class(creative_device):
    OnBegin<override>()<suspends> : void =
        Print("Hello, Verse!")
```


- `using` で使うモジュールを取り込んでいます。

- `class(creative_device)` で、島に置けるデバイスを定義しています。

- `OnBegin` が、ゲーム開始時に呼ばれる入口です。

- `Print` で画面とログへ文字を出しています。


見た目はPythonに近く、インデントでブロックを表します。  
一方で型検査は厳密で、この先の単元で見る「失敗可能式」や「エフェクト」のような、他の言語にない仕組みが中心になります。


## UEFNのインストール


この講座のコードを動かすには、UEFN（Unreal Editor for Fortnite）が必要です。  
インストールは、次の順番で行います（実機で確認した手順です）。


1. Epic Games Launcherへサインインします。
2. LauncherからFortniteをインストールします。
   途中で利用規約（TOS）への同意が求められます。
3. UEFNは、Fortniteとは別のライブラリアイテム「Unreal Editor for Fortnite」としてインストールします。
   インストール先は、Fortniteと同じフォルダーです。
4. UEFNを初めて起動すると、UEFN Supplemental Terms（補足条項）への同意が求められます。
5. プロジェクトブラウザーが開いたら、第2単元の手順で最初のプロジェクトを作ります。


Fortnite本体とUEFNは別々にインストールする点が、つまずきやすいところです。  
詳しい操作と実画面は、第2単元で扱います。
