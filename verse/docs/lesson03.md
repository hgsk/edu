# 第3単元 構文の基礎


[目次](../README.md) · [前の単元：第2単元 最初のデバイス](./lesson02.md) · [次の単元：第4単元 デバイス連携](./lesson04.md)


**この単元で学ぶこと：** `:=`、`=`、`set` の使い分けと、型の書き方、インデント、コメント、文字列の埋め込みを説明できるようになります。


## 定義、関数の本体、再代入


Verseでは、C++の `=` 一本にまとめられていた役割が、3つの書き方に分かれています。


- **`:=`（定義）：** 新しい名前を導入します。
  変数の初期化も、関数の定義も、クラスの定義も `:=` です。

- **`=`（関数の本体）：** 関数の定義では、引数と戻り値の型の後ろに `=` を置き、本体を続けます。

- **`set`（再代入）：** `var` で宣言した変数の中身を後から変えるときに使います。


```verse
Add(A : int, B : int) : int =
    Result := A + B
    Result
```


`Add` の本体の最後に書いた式 `Result` が、そのまま戻り値になります。  
`return` は早期に抜けるときだけ使うもので、通常は書きません。


```verse
var Count : int = 0
set Count = Count + 1
```


`var` でない定義は不変なので、`set` で変えることはできません。  
「変えるつもりの値だけ `var` にする」が基本の考え方です。


## 型は名前の後ろに書きます


```verse
Score : int = 0
PlayerName : string = ""
Add(A : int, B : int) : int = A + B
```


- 変数は「名前、コロン、型」の順です。

- 関数は「名前、引数（名前：型）、コロン、戻り値の型」の順です。

- 型の表記でよく使うものに、`int`（整数）、`float`（小数）、`string`（文字列）、`logic`（真偽）があります。
  真偽の値は `true` と `false` です。


## ブロックはインデントで表します


波括弧は使いません。  
行の字下げでブロックを作り、セミコロンも不要です。  
コメントは `#` から行末までです。


```verse
CheckScore(Score : int) : string =
    # ifも値を返す式です
    if (Score >= 60):
        "合格"
    else:
        "再挑戦"
```


`if` は文ではなく式で、選ばれた側の値がそのまま結果になります。  
三項演算子はありません。  
値の選択は `if` 式で書きます。  
論理演算は記号ではなく単語で、`and`、`or`、`not` と書きます。


## 文字列の埋め込み


```verse
ShowScore(Score : int) : void =
    Print("スコアは {Score} です")
    Print("2倍すると {Score * 2} です")
```


文字列リテラルの中の `{ }` には、変数だけでなく式も書けます。  
接頭辞は不要で、常に有効です。


## 確認


- [ ] `:=`、`=`、`set` をそれぞれ何に使うか説明できる

- [ ] `var` でない定義を `set` で変えられない理由を説明できる

- [ ] 型が名前の後ろに来る書き方で、変数と関数を1つずつ書ける


**演習：** 2つの `int` を受け取って大きい方を返す関数 `MaxOf` を書き、`if` 式を使ってください。  
さらに、結果を `Print` で「大きい方は { } です」の形で出す関数も書いてください。
