# 第8単元 コレクション


[目次](../README.md) · [前の単元：第7単元 非同期処理](./lesson07.md) · [次の単元：第9単元 状態と永続化](./lesson09.md)


**この単元で学ぶこと：** 配列とマップの型表記と作り方、不変性の考え方、`for` の2つの使い方（繰り返しと生成）を説明できるようになります。


## 配列


配列の型は `[]要素型` と書きます。  
値を作るときは `array{ }` の中に要素を並べます。

```verse
    Scores : []int = array{90, 75, 100}

    SumScores() : int =
        var Total : int = 0
        for (Score : Scores):
            set Total = Total + Score
        Total
```


`for (要素 : 配列):` で、要素を1つずつ取り出します。  
合計のような累積は、`var` の変数へ `set` で積み上げます。  
配列そのものは不変で、要素を後から書き換えることはできません。


## 範囲と生成子としてのfor


`0..9` は、両端を含む範囲を表します。  
`for` は、繰り返しの文としてだけでなく、列を作る式（生成子）としても使えます。

```verse
    Squares : []int = for (I := 0..9): I * I
```


この1行で、0から9までの二乗の配列ができます。  
条件を付けると、条件を満たす要素だけの列も作れます。

```verse
    BigScores : []int = for (Score : Scores, Score >= 80): Score
```


## マップ


マップの型は `[キー型]値型` と書きます。  
検索は失敗可能な式で、ある場合だけ取り出す書き方が基本です。

```verse
    LaneByName : [string]int = map{"left" => 0, "center" => 1, "right" => 2}

    ShowLane(Name : string) : void =
        if (Lane := LaneByName[Name]):
            Print("{Name} は {Lane} 番レーンです")
        else:
            Print("{Name} というレーンはありません")
```


プレイヤーをキーにする `[player]int` は、得点や経験値の管理で頻出します。  
内容を変えたいマップは `var` で宣言します。  
更新の書き方は第9単元で扱います。


💡 **ヒント：**

> 角括弧の使い分けに慣れてください。  
> 型の前では `[ ]型` が配列、`[キー]値` がマップ、式の中では添字アクセスと失敗可能な呼び出しです。  
> 文脈で役割が変わるのが、Verseの角括弧の特徴です。


## 不変性との付き合い方


配列とマップは値として扱います。  
「一部を書き換えた新しい値」を返すのが基本で、元の値は変わりません。  
C++の `std::vector` を直接書き換える感覚で使うと、思った場所で更新されていない、という形でつまずきます。  
更新が要る集合は `var` で持ち、代入の単位を意識して書きます。


## 確認


- [ ] `[]int` と `[string]int` の型表記が、それぞれ何を表すか説明できる

- [ ] `for` の生成子としての使い方で、配列を1行で作れる

- [ ] マップの検索が失敗可能で、`if` で受ける理由を説明できる
